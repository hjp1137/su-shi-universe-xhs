## 2. 核心架构与功能落地

### 2.1 XHSBridge 统一原生适配层 (`js/bridge.js`)
- **API 规范完整遵从**：
  1. `isAvailable()`：严格判定 `window.xhs && window.xhs.miniTool`；
  2. `writeTempFile(dataUri)`：严格校验 `dataUri` 必须以 `data:<mime>;base64,` 开头，杜绝裸 base64；真机调用 `window.xhs.miniTool.writeTempFile` 换取临时本地路径 `filePath`，非真机返回 `mock://temp/sushi_card_*.png`；
  3. `saveImage(filePathOrDataUri)`：自动支持传入 data URI 并先调 `writeTempFile`，再调用 `saveImageToPhotosAlbum({ filePath })`；支持真机权限拒绝识别与用户取消识别；
  4. `postNote(options)`：由用户显式点击触发，支持 `title`（≤20字）、`content`（≤1000字）、`pageType: "photo_publish"`、`mediaInfo: { image_resources: [{ url: filePath }] }`、`tags`；
  5. `openRedPage(type, params)`：通用原生页面跳转，参数校验与模拟降级；
- **错误码与用户取消归一化 (`isUserCancel`)**：
  - 精准识别 `cancel` 关键字，将 `postNote:fail cancel` 和 `saveImageToPhotosAlbum:fail cancel` 归一化返回 `{ success: false, canceled: true }`，不弹报错 Toast，只展示温和提示；
- **防并发调用锁 (`isBusy`)**：
  - 内部具备调用互斥锁，在 Native 处理期间屏蔽重复快速狂点，防止客户端并发崩溃；
- **Mock 模式支持 (`setMockMode`)**：
  - 支持设置 `'default'`、`'success'`、`'cancel'`、`'fail_auth'` 等模式，便于在无真机环境或自动化测试中完整覆盖全部分支。

### 2.2 分享卡视图双主链与反馈升级 (`js/views.js` & `css/views.css` & `js/ui.js`)
- **双核心操作主按钮**：
  1. `一键发布到小红书`：高贵金质主按钮，调起小红书发帖器，按钮进入 loading 态防止重复触发；
  2. `保存卡片至相册`：深靛蓝副主按钮，调用本地图片落盘与相册写入；
- **克制自然的预填发布文案**：
  - 人生站点卡：`我的苏轼人生站点 · 黄州｜原来我最近处在苏轼的「黄州」时刻。莫听穿林打叶声，何妨吟啸且徐行。遇到风雨，不如徐行自洽。#苏轼宇宙 #中国诗词宇宙 #东坡人生`
  - 今日东坡签：`今日东坡诗签 · 2026年9月7日｜今天在苏轼宇宙抽到了东坡诗笺：“莫听穿林打叶声，何妨吟啸且徐行。” 【放到今天】... 【今日一事】... #今日东坡 #诗词日历 #日常哲学 #苏轼宇宙`
  - 人生节点卡：`东坡行迹 · 密州｜行至「密州｜人到中年」。九万里风鹏正举，人生随处是东坡。#苏轼生平 #人生站点 #东坡行迹 #苏轼宇宙`
- **Toast 轻量提示组件 (`UI.showToast`)**：
  - 在 `js/ui.js` 和 `css/components.css` 中补齐纯原生 DOM 控制的 Toast 浮层，支持发布成功、取消发布、保存相册成功与权限引导温和提示，2.2 秒后平滑淡出，不遮挡主内容。
