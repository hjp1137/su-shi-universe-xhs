## 1. 任务概述与根因剖析

在任务 15.6.6 生产 ZIP 离线复验中发现 1 个确定性 P0 缺陷：
- **准确位置**：`css/components.css` 第 877~880 行之间。
- **根因分析**：前序任务在将单层 2.5D Fallback 样式插入 `components.css` 时，误删了前一条规则 `.constellation-nebula-glow` 的属性与闭合括号 `}`，遗留了未闭合的：
  ```css
  .constellation-nebula-glow {
    position: absolute;
    top: 0;
  /* 任务 15.6.6: 单层纯净 2.5D 东方星宿降级环 */

  ```
  这导致浏览器 CSSOM 解析到此产生语法错误，后续所有 15.6.6 新增样式（`.poetry-constellation-25d-fallback`、`.fallback-focus-node`、`.fallback-orbit-star`、`.fallback-orbit-title` 等）被浏览器静默丢弃。在关闭 WebGL 时，页面呈现裸文本、白按钮与标签重叠。
  旧测试仅以静态字符串判断代码存在（`assert in css`），未能探测到浏览器未真实解析，造成漏检。

- **修复与终极门禁体系**：
  1. **P0-A 语法闭合**：完整恢复 `.constellation-nebula-glow` 的完整属性与闭合 `}`，确保全量生产 CSS 括号 100% 结构平衡；
  2. **P0-B 浏览器 CSSOM 门禁**：通过真实 Chrome 浏览器读取 `document.styleSheets[].cssRules`，断言 8 个关键选择器真实存在于 CSSOM 且计算样式有效，同时覆盖源码与构建后的 `dist/css`；
  3. **P0-C 2.5D Fallback 运行复验**：真实强制禁用 WebGL，断言单层纯净东方星宿环、无白色 Chip、无旧 2D 叠层、点击作品星可自然聚焦与入画；
  4. **P0-D WebGL 主模式动态门禁**：单层架构硬断言（旧 2D 节点全部为 0）、手势拖拽 PoetryPlanet 屏幕投影坐标位移（位移和达 201px > 15px）、点击《念奴娇·赤壁怀古》平滑自转居中偏上放大 2.0 倍并附着微胶囊，绝无独立大矩形卡；
