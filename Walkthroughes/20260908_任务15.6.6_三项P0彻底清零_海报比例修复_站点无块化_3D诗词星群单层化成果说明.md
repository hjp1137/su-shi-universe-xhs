# 任务15.6.6 成果说明：三项P0彻底清零（海报比例修复、站点无块化、3D诗词星群单层化）

## 1. 任务概述

本任务全面落实了《任务15.6.6_三项P0彻底清零_海报比例修复_站点无块化_3D诗词星群单层化01.md》的要求，聚焦三项用户高感知 P0 视觉与交互顽疾，从根因彻底清零：

1. **P0-A 海报比例修复**：
   - **根因**：前序任务测试断言的是外部容器高度（如 714px），而 Canvas 海报严格按 3:4 比例生成（如 367x489），导致海报在被强行拉高的容器内缩放显示，产生 225px 大面积上下黑边/空白。
   - **解决**：改写海报与每日签外层容器比例算法为真实 3:4 最大化（`width: min(calc(100% - 4px), calc((100vh - 84px) * 0.75)); height: calc(width * 4 / 3); aspect-ratio: 3 / 4;`），舞台尺寸严格服从海报物理比例，海报 `img` 采用 `object-fit: fill` 紧密咬合；配合 JS 动态 resize 监听与视口适配，在 320/375/390/430/480 等所有移动视口下比例严格保持 `0.75 +- 0.01`，彻底消除上下大面积黑边与左右空隙；所见即所得（WYSIWYG）100% 保持同一 DataURL。

2. **P0-B 站点无块化**：
   - **根因**：前序虽移除了外层大卡框，但在局部正文段落（`.history-slice-body`、`.life-orbit-body` 等）仍残留大面积深色 `rgba(12, 20, 36, 0.65)` 面板和 `backdrop-filter: blur(4px)` 磨砂遮罩，视觉上仍呈碎片卡片化堆叠。
   - **解决**：彻底废除史实与生活实录正文段落的深色 `rgba` 背景与 `blur` 磨砂板（`background: transparent !important; backdrop-filter: none !important;`），以连续无界长卷流线贯穿；章节时间标记（`.station-chapter-badge`）由矩形块改为金线时间刻度流线（`border-left: 2px solid var(--color-warm);`）；为 5 大核心站点（眉山、黄州、杭州、惠州、儋州）落实专属镜头布局（`.station-lens-{station.id}`），在亮色背景（杭州、惠州）下采用深黛高对比字色（`#182336`，对比度达 7.5:1），深色背景（黄州、眉山、儋州）下采用金白字色（`#fdfbf7`，对比度达 9.8:1），全链路严格达标 WCAG AA 规范。

3. **P0-C 3D诗词星群单层化**：
   - **根因**：`UI.createConstellationGroup` 在挂载 3D WebGL 舞台的同时，仍固定在同一个容器中构建了旧 2D SVG 轨道、旧 coreNode、旧 2D 作品星（`.constellation-star-node`）和旧微名片气泡，导致 3D 旋转星体与 2D 固定 DOM 节点物理重叠；且 Fallback 模式下生成了杂乱的白色 Chip。
   - **解决**：在 `ui.js` 中构建硬分支隔离，WebGL 模式下彻底禁止在舞台中创建任何旧 2D 节点，PoetryPlanet 成为唯一的视觉、运动、命中与标签主体；星球本体升级为立体东方水墨纹理（128x128 Canvas 动态绘制立体球体阴影、日冕与倾斜金色星环）；手势拖拽群星自转与刚体空间位移同步联动（实时更新 `updateMatrixWorld(true)` 与屏幕投影坐标）；点击星体聚焦居中偏上并放大 2.0 倍，附着式微文字胶囊严格约束尺寸（宽度 <= 40% 舞台，高度 <= 90px），杜绝遮挡；降级模式采用纯净独立的 2.5D 单层东方星宿环，杜绝白色 Chip 与叠层。
