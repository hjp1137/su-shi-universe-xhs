## 一、任务背景与核心目标

在任务 14.1 完成全站功能、史实勘误与离线单页发布包验证的基础上，任务 15 全面升级视觉语言，彻底告别“普通深色文化 H5”，将其重构为“可漫游的东方诗词宇宙”。在保留已验证的业务逻辑、数据实体、Classic Script 链与纯离线特性的前提下，实现以下突破：
1. **东方水墨美学确立**：确立“现代水墨 × 深靛蓝 × 月色 × 江水 × 微星图 × 人间烟火”的东方宇宙视觉基调；
2. **四层空间深度与解耦容器**：底色夜幕（Level 0）、远山星轨（Level 1）、解耦背景特效容器 `#universe-bg-fx`（为任务 15.1 WebGL 预留纯净挂载点）、前景 DOM 语义卡片（Level 2-3）；
3. **九大人生站点色彩意象与情绪转折**：从眉山翠青、京师曙蓝、密州苍灰、乌台至暗墨雨，到黄州江月破晓、杭州暖湖、惠州岭南荔红、儋州天涯沧溟、常州返璞暖金；
4. **四大语义卡片质感体系**：人生站点卡（`.ink-card-station`）、诗词宣纸卡（`.ink-card-poem`）、今日东坡日历信笺卡（`.ink-card-daily`）、结果解读卡（`.ink-card-narrative`）；
5. **全流程移动端自动化真机视口留证**：基于标准 390×844 视口截取 7 张关键页面高保真截图并归档；
6. **官方 Skill 1.6.0 双引擎审计与全量测试回归**：产出最新标准 ZIP 包，大小 123.41 KB，双引擎双对象 0 warning 0 error，11 套自动化测试 100% 通过。

## 二、核心实施细节与架构解耦

### 1. 设计规范文档落地
- 编写并落盘 `docs/11_视觉系统2.0与东方诗词宇宙设计规范.md`，从视觉哲学、四层空间体系、九大人生站点色彩情绪表、四大语义卡片质感规范、移动端视口与无障碍动效等方面确立全站视觉统一依据。

### 2. Design Tokens 2.0 升级 (`css/tokens.css`)
- 扩展多层空间深度变量：`--bg-cosmos-deep` (#080c14)、`--bg-cosmos-mid` (#0d1527)、`--bg-cosmos-light` (#131e36)、`--bg-mist-layer`、`--bg-moon-glow`；
- 扩展九大人生站点专属色温变量：`--station-meishan` (#1f4a3b)、`--station-jingshi` (#1e3352)、`--station-mizhou` (#38424d)、`--station-wutai` (#141923)、`--station-huangzhou` (#4a2d18)、`--station-hangzhou` (#224b42)、`--station-huizhou` (#42262d)、`--station-danzhou` (#1b3547)、`--station-changzhou` (#45331e)；
- 建立四大语义卡片质感变量（渐变底色、内发光、微边框、东方水墨阴影）。

### 3. 解耦背景层与 App Shell (`index.html`, `css/base.css`)
- 在 `index.html` 的 App Shell 引入独立背景容器 `#universe-bg-fx`，其层级低于 `#app` 与滚动容器，实现 DOM 内容层与背景特效层的绝对解耦；
- 在 `css/base.css` 中实现微星图流光、远山云雾微漂移、水波江月微澜。当环境不支持 WebGL 或任务 15.1 尚未注入时，纯 CSS 粒子与水墨背景无缝降级生效；
- 严格遵循 `prefers-reduced-motion: reduce` 规范，低动效模式下禁用星轨漂移与缩放。

### 4. 四大语义卡片与核心视图重构 (`css/components.css`, `css/views.css`, `js/views.js`)
- **首页**：Hero 主标重构为“行过天涯，终见东坡”，主行动按钮命名为“进入我的东坡时刻”，新增“今日东坡”精选卡片与“漫游九大站点”入口；
- **测试页**：新增东方星月步进器、水墨水波选项涟漪动效与水墨宣纸卡片；
- **结果页**：七层叙事卡片（人生状态金句、东坡历史现场、行迹地图、代表作品、今日哲学、随身解法、生成分享卡），全量挂载 `data-station-id` 站点专属色温浸润系统；
- **漫游页**：九大站点生命长河星轨展开，节点按站点情绪色彩绑定 `.rhythm-*` 发光徽章；
- **作品详情页**：东方水墨宣纸质感卡片，名句书法提亮，现代生活解法启发；
- **今日东坡**：东方日历信笺排版，新增“东坡朱砂印泥签印”（`.daily-seal-stamp`）；
- **分享卡预览**：画轴装裱感外框（`.share-scroll-frame`）与一键发布至小红书/保存相册双主链。
