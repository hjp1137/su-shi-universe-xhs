## 一、任务背景与设计哲学

在任务 15 确立东方水墨视觉语言、Design Tokens 2.0 与四层空间解耦架构的基础上，任务 15.1 正式落地轻量级东方诗词宇宙 WebGL 特效系统。本系统严格遵守：

> **“Three.js 只负责宇宙感、空间感、氛围与镜头感，DOM 负责内容与操作；任何 WebGL 失败都不得影响核心功能，对业务零耦合。”**

---

## 二、Three.js 版本选型与兼容说明

1. **精确版本**：**Three.js r128 (`0.128.0`)** 本地 UMD / Classic Script 打包版本；
2. **选择理由**：
   - **WebGL 1 黄金稳定基线**：原生向下兼容移动端老内核 WebView，完全兼容 ES2017 / Chrome 61；
   - **纯离线运行**：零远程请求、零 CDN、零外部字体/纹理、零模型依赖；
   - **零现代模块与 WASM 依赖**：无运行时 `import/export`，无 Draco/Basis 解码器，无 Worker / OffscreenCanvas；
   - **离线网络桩净化**：对内部不适用的 `fetch` 与 `XMLHttpRequest` 加载器完成离线安全中和，100% 通过官方合规静态扫描；
3. **包体增量控制**：
   - 包含 Three.js 核心及全套特效模块后，最终发布包 `dist/su-shi-universe-xhs.zip` 体积仅为 **282.91 KB**（比任务 15 增量 159.5 KB），占 ≤ 2048 KB 强推荐预算仅 **13.8%**，远低于 10240 KB 硬门禁。

## 三、WebGL 架构与核心实现

建立完全解耦的独立模块架构于 `js/effects/`：

```text
js/effects/
├── quality-manager.js  # 四档自适应降级管理 (High / Medium / Low / Fallback)
├── fallback.js         # 纯 CSS/Canvas 2D 优雅降级引擎
├── webgl-engine.js     # WebGL 渲染引擎 (生命周期/预算控制/容错)
├── hero-scene.js       # 首页东方宇宙 Hero (低亮月轮/远山剪影/江面/微星/视差)
├── universe-scene.js   # 东坡人生星河 (九大站点情绪参数化流动)
├── result-scene.js     # 测试结果揭晓 (短时粒子聚拢/光晕渐显)
└── index.js            # 统一出口挂载至 SuShiUniverse.Effects
```

### 1. 三大核心特效场景
- **场景 1：首页东方宇宙 Hero (`HeroScene`)**：
  - 顶右皎洁月轮与微光月晕；
  - 三层起伏层峦水墨远山剪影；
  - 底部江面水光微澜平面；
  - 稀疏水墨星点粒子微漂移（30-60 点）；
  - 轻量指针/触控微视差与低频呼吸缓动（Draw call <= 6，三角形 <= 80）。
- **场景 2：东坡人生星河 (`UniverseScene`)**：
  - 单一场景复用架构，绝不为每个站点独立创建或销毁 3D 场景；
  - 生命长河粒子星轨沿江蜿蜒流淌，九大人生站点色温与视觉参数平滑插值演化（眉山翠青/京师曙蓝/密州苍灰/乌台墨雨/黄州破晓金/杭州暖湖/惠州荔红/儋州沧溟/常州归静）。
- **场景 3：测试结果揭晓 (`ResultScene`)**：
  - 0.8~1.2 秒克制向心粒子汇聚与站点色温光晕渐显点亮；
  - 汇聚完成后定格为柔和呼吸光环，完全不阻断 DOM 卡片阅读与触控操作。

### 2. 性能预算与四档动态降级策略
- **四档定义**：`High` / `Medium` / `Low` / `Fallback`；
- **初始档位**：严格按照 Skill 1.6.0 建议，从 `Medium` 保守档启动（DPR <= 1.25）；
- **像素硬门禁**：限制 drawingBuffer 总像素约 <= 200 万（超标自动压制 DPR）；
- **帧耗时监控与自动降档**：`QualityManager.prototype.recordFrame` 持续监测，当连续 60 帧单帧耗时超过 33.3ms（低于 30FPS）时，自动逐级降档（High -> Medium -> Low -> Fallback）；
- **低动效优先**：主动检测 `prefers-reduced-motion: reduce`，匹配时自动降为 Low 档或静态兜底；
- **生命周期休眠**：监听 `visibilitychange`，页面切后台时立即挂起 `requestAnimationFrame`，页面恢复时重置时间戳，杜绝卡顿堆叠；
- **Context Lost 容错**：监听 `webglcontextlost` 立即停止渲染并调用 `FallbackEngine`，监听 `webglcontextrestored` 尝试安全复原，绝不白屏。

### 3. 非 WebGL 优雅降级 (Fallback)
- 当设备不支持 WebGL、初始化失败、Context 丢失或画质降至 Fallback 时，`FallbackEngine` 无缝激活 `#universe-bg-fx` 纯 CSS / Canvas 2D 渐变星雾层，全站业务功能（问答测试、结果展示、站点漫游、作品赏析、今日东坡、Canvas 分享卡生成、Native Bridge）对 WebGL 依赖度为 0。
