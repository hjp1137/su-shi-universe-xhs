## 2. 核心架构与功能落地

### 2.1 东方古典水墨动效氛围体系 (`css/tokens.css`, `css/base.css`, `css/components.css`, `css/views.css`)
- **设计令牌扩展**：在 `tokens.css` 中扩展水墨缓动与周期规范：`--motion-enter: 280ms cubic-bezier(0.16, 1, 0.3, 1)`、`--motion-breathe: 4800ms ease-in-out infinite alternate`、`--motion-pulse: 2600ms cubic-bezier(0.25, 0.8, 0.25, 1) infinite`；
- **全应用水墨底蕴**：
  1. `app-shell::before`：增加低频漫流的月光水晕层，利用 `opacity` 在 0.45~0.75 间缓慢呼吸 (`inkAmbientBreathe`)，零重排损耗；
  2. `.view-wrapper`：全逻辑视图切入时统一执行平滑淡入轻微上浮入场动画 (`viewFadeIn`)；
  3. 首页 Hero：徽标添加微浮动效 (`homeLogoFloat`)，今日东坡诗词轻预览卡添加水墨微呼吸与触控墨色高亮；
  4. 问答测试页：题目卡切换平滑入场 (`quizCardIn`)，选项具有轻回弹缩放与微光选中态；
  5. 结果页七层叙事：采用阶梯式延迟入场 (`resultCardStagger`)，使主站点、历史层、现代解读、今日小行动顺序舒展；
  6. 漫游生命线：当前所在结果站点与关键转折点徽标增加低频扩散光圈 (`stationBadgePulse`)；
  7. 作品与诗词：名句卡片增强月白色光晕与字距呼吸感；
  8. 分享卡生成：卡片图片增加画卷成形平滑过渡动效 (`cardRollIn`)。

### 2.2 Chrome 61 CSS 集中纠偏与移动端体验收口
- **Flex Gap 纠偏**：
  - 修复 `views.css` 中 `.share-card-actions` 等区域对原生 `gap:` 的裸漏依赖；
  - 补齐符合 Chrome 61 标准的兄弟选择器间距（`> * + *`），杜绝在老核浏览器上按钮紧贴无间距；
- **Aspect-Ratio 回退基线**：
  - 针对分享卡等媒体容器，增加 `min-height: 400px;` 基线兜底，防止 Chrome 61 在尚未加载图片或无 `aspect-ratio` 支持时发生容器高度塌陷；
- **触控反馈与防误触**：
  - 全局按钮、交互卡片添加 `:active` 细腻触控反馈（`scale(0.97)` 及背景色微调）；
  - 为所有按钮与导航操作添加 `user-select: none; -webkit-user-select: none;`，杜绝真机长按触发文本选择框；
  - 巩固全局 `touch-action: manipulation;`，消除真机 300ms 点击延迟；
- **双安全区与防溢出**：
  - 顶部导航栏与底部操作栏统一使用 `var(--safe-area-top)` 与 `var(--safe-area-bottom)`，内置 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))` 双兼容语法；
  - 主容器 `overflow-x: hidden;`，诗词长标题与正文设置 `word-break: break-word;`，在 320px~480px 各种屏幕下均无横向滚动条。

### 2.3 性能与无障碍系统降级保障
- 全局注入 `@media (prefers-reduced-motion: reduce)`：
  - 当系统开启“减弱动态效果”或处于低功耗模式时，所有动画时长自动降为 `0.01ms !important`，保留完整排版，杜绝动画闪烁与多余电量消耗。
