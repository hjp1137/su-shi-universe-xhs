- **品牌锚点**：呈现“中国诗词宇宙 · 人物实验”徽章、月波矢量印记、4px 间距的“苏轼宇宙”大标题；
- **情感触达**：Slogan“遇到烦心事，先去东坡那里坐一会儿。”与副说明“7道生活化小题 · 看看你更像走在东坡哪一站”；
- **一屏核心 CTA**：放置首屏最强主按钮 `看看我的人生正在东坡哪一站`（`.home-main-cta`），江水青与苍竹玉渐变，390x844 视口下一览无遗，点击直接进入 `quiz` 逻辑视图；
- **今日诗句微卡片**：轻量虚线月晕卡片，呈现当日稳定精选诗句，点击直达 `daily` 视图。

### 2.2 三大体验路径卡片化呈现
在首屏下方以卡片列表组织三大核心入口：
1. **测一测｜你的人生正在东坡哪一站？**（`.nav-quiz`，江水青左指示条，带“主推荐”标识，引导进入人生状态测试）；

3. **坐一会｜今日东坡小笺**（`.nav-daily`，暖灯火左指示条，带“每日一诗”标识，引导进入今日一言一事）。

## 三、Chrome 61 与合规工程处理

1. **CSS Chrome 61 兼容**：
   - 弹性相邻兄弟选择器（`> * + *`）保障垂直间距，不唯一依赖 Flex gap；
   - 统一采用系统可用字体栈，避免远程在线字体加载；
   - 全局背景与微光采用纯 CSS 径向渐变与 SVG 矢量图，零外部大图网络资源依赖。
2. **安全区与视口**：
   - 继承 App Shell 双兼容安全区：`var(--safe-area-top)` 与 `var(--safe-area-bottom)`；
   - 容器尺寸自适应，小屏幕（320px—480px）无横向溢出，首屏主 CTA 稳居可视区内。
3. **CSP 与交互规范**：
   - 全部按钮与卡片点击均通过 `addEventListener` 绑定，绝无行内 `onclick=` 属性；
   - 脚本严格遵循 Classic Script 依赖顺序加载。
