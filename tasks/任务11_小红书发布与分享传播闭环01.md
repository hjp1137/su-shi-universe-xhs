# 任务11 小红书发布与分享传播闭环 0.1

> 项目：苏轼宇宙小红书小工具  
> 阶段：Competition Polish  
> 前置任务：任务1.1、任务2—10  
> 任务优先级：P0

## 一、任务目标

基于 Skill 1.6.0 已确认的 Native Bridge，打通：

> **测试/浏览 → 分享卡 → 写临时文件 → 保存相册或调起发布 → 成功/取消/失败反馈 → 返回产品。**

本任务不得再以“平台 API 待确认”为前提，正式依据为：

```text
window.xhs.miniTool.writeTempFile
window.xhs.miniTool.saveImageToPhotosAlbum
window.xhs.miniTool.postNote
window.xhs.miniTool.openRedPage
```

具体参数、回调/Promise 形式、媒体数量和客户端限制仍必须以当前实际安装的 `jsbridge-api.md` 为准。

## 三、XHSBridge 统一适配层

页面和业务模块不得到处直接调用 `window.xhs.miniTool.*`。

至少提供：

```text
XHSBridge.isAvailable()
XHSBridge.writeTempFile(dataUri)
XHSBridge.saveImage(filePathOrSupportedInput)
XHSBridge.postNote(options)
XHSBridge.openRedPage(options)
```

适配层统一负责：

- Bridge 存在性检测；
- Promise/回调差异封装；
- 参数校验；
- 错误码归一化；
- 用户取消识别；
- PC 模拟器降级；
- 日志边界。

## 四、分享主链

推荐正式流程：

```text
Canvas 2D 生成卡片
↓
得到完整 data URI / 本地图片数据
↓
writeTempFile
↓
获得 filePath
↓
用户选择：
├─ saveImageToPhotosAlbum
└─ postNote
↓
成功 / 取消 / 失败
↓
恢复原产品状态
```

不得使用：

- `<a download>`；
- 网络上传换 URL；
- fetch；
- 远程文件中转；
- 自动发布。

## 五、postNote 规则

调用 `postNote` 前必须：

- 由用户主动点击触发；
- 传入 Skill/API 允许的本地素材；
- 在调用前让用户看到最终分享卡；
- 不绕过用户确认；
- 失败/取消后返回工具且状态完整。

如接口允许预填标题/正文，使用自然、克制文案，例如：

- `原来我最近在苏轼的“黄州站”。`
- `今天抽到了一句东坡：莫听穿林打叶声。`
- `遇到烦心事，去东坡那里坐了一会儿。`

不得诱导性自动发帖。

## 六、saveImageToPhotosAlbum 规则

- 只传 API 明确支持的本地路径或 base64/data URI 形态；
- 不传 HTTP 网络 URL；
- 权限拒绝要给出温和说明；
- 用户取消属于正常分支；
- 保存失败可重试，但不死循环。

## 七、openRedPage

仅在产品确实需要站内原生跳转时使用。

- 必须命中 Skill/客户端允许白名单；
- 不把它当任意 URL 浏览器；
- 不用来规避离线限制。

V1 如无必要，可只保留封装与能力测试，不强行加入产品主链。

## 八、异常与降级

必须覆盖：

1. `window.xhs` 不存在；
2. `miniTool` 不存在；
3. PC 模拟器能力不完整；
4. `writeTempFile` 失败；
5. 用户拒绝保存权限；
6. 用户取消保存；
7. 用户取消发布；
8. `postNote` 失败；
9. 卡片文件不存在；
10. 重复点击导致并发调用。

任何失败都不得让用户卡死在 Loading。

## 九、本地事件

如需要产品调试事件，只做本地抽象：

```text
share_preview_open
share_card_generated
save_start/save_success/save_cancel/save_fail
publish_start/publish_success/publish_cancel/publish_fail
```

**禁止接入外部分析服务或网络埋点 SDK。**

## 十、验收标准

- XHSBridge 集中封装；
- `writeTempFile` 有真实成功/失败测试；
- `saveImageToPhotosAlbum` 有真实测试或明确环境限制；
- `postNote` 有真实测试或明确环境限制；
- 不支持场景有降级；
- 用户取消不会被当成严重错误；
- 发布前由用户主动触发；
- 分享卡与最终发布素材一致；
- 返回工具后状态稳定；
- 无网络请求；
- 无 `<a download>`；
- Chrome 61 / ES2017 合规；
- 阶段官方 audit 无阻塞问题。
