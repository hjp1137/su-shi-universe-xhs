## 一、Three.js 版本选型与选择理由
- **精确版本**：Three.js r128 (`0.128.0`) 本地 UMD / Classic Script 离线打包版本；
- **选择理由**：
  1. 移动端 WebView / WebGL 1 兼容性的黄金稳定基线，原生向下兼容 ES2017 / Chrome 61；
  2. 纯离线运行，零远程请求，零外部字体/纹理/模型依赖；
  3. 零运行时 ESM、零 WASM、零 Worker 依赖；
  4. 网络加载器经离线桩安全中和，100% 满足官方静态安全扫描。

## 二、WebGL 架构与核心场景
1. **模块架构**：建立完全解耦的 `js/effects/` 模块群（`quality-manager.js`, `fallback.js`, `webgl-engine.js`, `hero-scene.js`, `universe-scene.js`, `result-scene.js`, `index.js`），通过 `SuShiUniverse.Effects` 统一暴露；
2. **场景 1 (Hero)**：低亮月轮、三层水墨远山剪影、江面微澜、稀疏微星漂移与指针轻量视差；
3. **场景 2 (Universe)**：单一场景架构复用，长河星轨粒子沿江蜿蜒，九大站点专属色温与氛围参数平滑插值演化；
4. **场景 3 (Result)**：0.8~1.2 秒向心粒子汇聚与站点光晕定格，不阻塞 DOM 卡片阅读与操作。

## 三、性能预算与四档动态降级
- **四档定义**：`High` / `Medium` / `Low` / `Fallback`，从 `Medium` 保守档启动（DPR <= 1.25）；
- **预算硬门禁**：总像素 <= 200万，连续 60 帧耗时 > 33.3ms 自动降档；
- **容错与兜底**：`visibilitychange` 后台挂起、`webglcontextlost` 停帧保护与 `FallbackEngine` 纯 CSS / Canvas 2D 无缝接管，核心业务对 WebGL 依赖度为 0。
