## 二、架构设计与落地成果

### 2.1 样式与视觉系统分层
彻底消除单体 CSS 混乱定义，重构为 4 层职责清晰的模块化规范样式：
1. `css/tokens.css`：统一集中管理 Design Tokens，涵盖色彩系统（深靛蓝、月白、墨蓝、江水青、苍竹玉、暖灯火）、4pt/8pt 间距系统、排版字阶、圆角、阴影、层级与容器双安全区变量。
2. `css/base.css`：全屏固定容器高宽与防横向溢出约束，纯 CSS 径向/线性渐变月光意境水墨背景，Chrome 61 flex-gap 降级兜底兼容层。
3. `css/components.css`：统一通用 UI 基础组件样式（NavBar、BackButton、SectionHeader、PrimaryButton、SecondaryButton、InkCard、QuoteBlock、TagGroup、ProgressBar、LoadingState、EmptyState、ErrorState）。
4. `css/views.css`：8 大核心逻辑视图原型壳层排版与视觉展现样式。

### 2.2 离线轻量视图路由器 (`js/router.js`)
- 挂载于 `window.SuShiUniverse.Router`，完全离线运行；
- 预留并接入 8 个核心逻辑视图状态：`home`（首页）、`quiz`（测试问答）、`result`（结果揭晓）、`universe`（宇宙生命线）、`station`（站点详情）、`work`（作品赏析）、`daily`（今日东坡）、`share-card`（分享卡预览）；
- 提供 `navigate(name, params)`、`back()`、`getCurrentView()`、`getParams()`、`onViewChange(cb)` 等轻量状态路由 API，管理内存历史栈与各视图渲染/销毁生命周期。

### 2.3 通用 UI 组件构建库 (`js/ui.js`)
- 挂载于 `window.SuShiUniverse.UI`；
- 提供安全的 DOM 构建辅助函数，全部采用原生 DOM API 创建与赋值，彻底杜绝未过滤 HTML 注入风险；
- 交互事件统一采用 `addEventListener` 绑定，严格杜绝行内 `onclick` 等不合规模式。

### 2.4 数据底座联动与骨架联动 (`js/views.js` & `js/app.js`)
- 视图层直接消费 `window.SuShiUniverse.Data` 中的真实史料数据；
- App Shell 动态感知视图变化，自动更新顶部导航标题，动态挂载 44x44px 安全返回按钮；
- 处理异常边界与空状态，保障任何无效参数均有诗意文案与优雅恢复路径。

## 四、Chrome 61 与双安全区兼容实现

1. **双安全区兼容**：
   在 `css/tokens.css` 中严格定义：
   ```css
   --safe-area-top: var(--safe-area-inset-top, env(safe-area-inset-top, 0px));
   --safe-area-bottom: var(--safe-area-inset-bottom, env(safe-area-inset-bottom, 0px));
   --safe-area-left: var(--safe-area-inset-left, env(safe-area-inset-left, 0px));
   --safe-area-right: var(--safe-area-inset-right, env(safe-area-inset-right, 0px));
   ```
   并在 `.app-header` 与 `.app-footer` 集中应用，各业务逻辑视图无需重复处理。
2. **Chrome 61 兼容保障**：
   - 布局不唯一依赖 `gap`：采用 `> * + *` 相邻兄弟选择器设定 `margin-top` / `margin-left` 作为基准，保障低版本内核完全对齐；
   - 杜绝 CSS `aspect-ratio`、`:has()`、`clamp()` 等现代非兼容属性；
   - JS 严格遵循 ES2017，无可选链 `?.`、无空值合并 `??`、无动态 import。
