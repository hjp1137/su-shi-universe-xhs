# 任务15.6.8｜结果页减法、九站测试校准、今日东坡职责拆分、Canvas海报重构与新增场景资源接入

## 一、任务背景

15.6.7 已经在部分站点详情页实现“图文分层”，但直接运行与用户随机体验继续暴露出四类真实问题：

1. **测试结果页（标题为“东坡站点”）仍是旧式图上压字结构**。它与后续“站点详情页”是两条不同页面链路，15.6.7 主要整改了后者，导致前者仍存在图片被标题、年份、标签、题记等覆盖，以及正文受动态背景干扰的问题。
2. **人生实验结果存在明显杭州偏置**。当前 mood 累加 + 固定 `primary_station_id` 的机制实际只覆盖部分人生站点，且随机回答高概率落入杭州，不能代表“九站人生映照”的产品设定。
3. **今日东坡同时承担每日阅读页与传播海报页**，导致同一场景图重复出现、内容过载、主次不清。
4. **站点详情与 Canvas 海报仍存在重复用图和图上堆字**。用户希望图片成为视觉主体，文字下移到独立信息区；若页面需要多张大图，同一张图不得在同一页面重复出现。

本任务不再泛化美化全站，而是集中解决以上问题，并把用户已经放入本地工作区 `assets/images/scenes/` 的新增资源正式接入代码和 Git。

# 二、任务总目标

完成以下五项收口：

1. **测试结果页极简化 + 图文彻底分层**：结果页只负责“揭晓你的人生站点”，不再与站点详情重复讲大量内容。
2. **人生实验评分重构为九站全部可达的标准化映射**：修复杭州过度集中和四站永远不可达的问题。

4. **Canvas 三类卡片重新构图**：图片占主视觉，图片区域最多保留 0～2 行短文本，长文本全部下移。
5. **新增场景资源接入 + 同页图片去重**：京师/黄州/杭州首先使用新增资源建立 Hero / Quote / Life 的多图场景体系；其余站点不得强制重复使用同一张大图。

# 四、P0-A｜测试结果页减法与图文分层

## 4.1 页面职责重新定义

测试完成后进入的“东坡站点 / result”页只负责：

> **揭晓用户最接近哪一个苏轼人生站点，并制造第一视觉高潮。**

不得继续承担完整站点百科/长篇解释职责。

推荐结构：

```text
[全宽场景图，图片本身清晰展示]

你的东坡站点
杭州｜把日子过好
1089—1091 · 浙江杭州

一句结果解释（1～2行）
一句代表题记（可选）

[进入杭州小宇宙]
[生成我的东坡人生卡]
```

### 硬约束

- 图片区域与正文信息区必须为两个独立布局区域；
- 站名、年代、4个关键词、长题记不得同时压在图片上；
- 图片上最多允许一个极轻量短标识，例如“人生第6站”；
- 普通正文与主图重叠面积目标 **0%**，不得超过5%；
- 禁止重新用大面积 `rgba` / `blur` / `backdrop-filter` 把图片压灰后承托文字；
- 结果页正文背后必须是稳定底色，粒子/大光斑不得影响文字可读性；
- 结果页内容必须明显少于 station detail，避免用户连续两页阅读重复内容。

## 4.2 结果页与详情页职责分离

结果页：
- “你是谁 / 你落在哪一站”；
- 一句解释；
- 一个主 CTA。

站点详情页：
- 历史现场；
- 代表名句；
- 生活实录；
- 诗词星群；
- 当代启发。

禁止把详情页内容复制回 result 页。

# 五、P0-B｜人生实验九站评分重新校准

## 5.1 禁止继续使用“8 mood → 固定5站”的最终判定方式

当前基于 mood 原始分值累加后直接读取 `primary_station_id` 的方法必须升级。

2. 京师
3. 密州
4. 乌台
5. 黄州
6. 杭州
7. 惠州
8. 儋州
9. 常州

**九站必须全部理论可达、测试可达、实际可达。**

## 5.2 推荐评分架构

优先复用当前人生实验已有的心理/行为维度，建立：

```text
答题选项
  ↓
统一归一化 trait vector
  ↓
7题聚合用户向量
  ↓
标准化
  ↓
九站 station affinity profile
  ↓
距离/余弦相似度/加权匹配
  ↓
Top1 = 人生站点
Top2/Top3 = 结果解释辅助
```

允许具体实现采用加权距离、余弦相似度或等价的确定性方案，但必须满足：

- 每个选项的总贡献量应归一化，不能因为某一维在大量选项中“顺手+1”而累计碾压；
- 九个站点必须具有独立 affinity profile；
- 同一组7题、同一回答在一次 session 内结果必须稳定；
- 重新开始后即使抽到另一组题，也应在用户倾向相近时保持合理稳定，而不是纯随机站点；
- 结果解释要从用户 Top traits + 站点 profile 生成，不得输出伪科学精确结论；
- 明确这是“人生映照/文化互动”，不是医学或临床心理诊断。
