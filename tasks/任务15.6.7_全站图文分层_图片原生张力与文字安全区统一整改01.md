# 任务15.6.7｜全站图文分层、图片原生张力与文字安全区统一整改

> 任务性质：Visual 2.0 最后一轮全站视觉规则统一整改
>
> 前置基线：`main` 当前基线为 `93d3284b98c4289bcac41bf4c480bad7ab2383de`，任务15.6.6.1 已通过直接运行复验，CSSOM / 3D / Fallback P0 已关闭。
>
> 本任务不是再次重构首页、人生星河、心理实验、3D诗词星群等已稳定主结构，而是解决当前全站仍普遍存在的一个视觉根因：**文本过度叠压在图片或动态背景上，导致图片失去张力、文字可读性不稳定、页面出现“图+遮罩+字”的模板化H5感。**

---

## 1. 任务目标

将全站视觉关系从：

> **图片 + 遮罩 / 磨砂层 + 多层文字叠加**

统一升级为：

> **图片负责情绪与视觉张力，文字负责信息与阅读节奏；默认图文分层，仅在真正的海报/封面场景允许极少量短文字压图。**

完成后应达到：

1. 东坡站点页不再出现明显“文字与背景融为一体、看不清”的情况；
2. 普通内容页大图优先完整直出，标题、年代、标签、正文整体下移到独立文本区；
3. 图片不再被大面积统一遮罩、blur、半透明板覆盖；
4. 页面长卷更像“数字人物画册 / 叙事长卷”，而不是“图文组件列表”；
5. 动态粒子、WebGL高亮、巨大光斑必须避让正文区域；
6. 今日东坡、卡片预览等页面中，**页面UI**遵循图文分层，而**最终3:4传播海报 Canvas**允许少量经设计的短文字压图，但不得把长解释塞进图片视觉区；
7. 本任务完成后必须重新生成最终生产 ZIP，并交付直接运行复验；未通过人工运行复验不得进入任务16。

# 2. 全站新增最高级视觉规则

## 2.1 核心原则：图文分层，而不是图文叠层

普通内容页默认结构应是：

```text
大图 / 场景图
↓
标题 / 时间 / 标签
↓
正文 / 解释 / 行动
↓
下一张大图 / 下一幕
```

禁止默认结构继续是：

```text
大图
+ 标题
+ 年代
+ 标签
+ 金句
+ 正文
+ 半透明遮罩 / 磨砂层
```

### P0规则

除本任务明确允许的“海报型短文字叠图”外，普通页面中的：

- 一级标题；
- 年代 / 地点；
- 3个以上标签；
- 正文段落；
- 现代解读；
- 行动建议；
- 长诗句 / 长引用；

**不得整体叠在照片/场景图内部。**

这些信息必须进入图片下方或图片之外的独立排版区。

---

## 2.2 单张图片允许的文字上限

普通内容页单张图片最多允许 **1～2层短文字**，例如：

- `1057 · 苏轼入京`
- `京师｜一举成名`

或一行极短场景题记。

不得同时在一张图上叠加：

- 品牌名；
- 主标题；
- 副标题；
- 年代；
- 地点；
- 四个标签；
- 长金句；
- 正文。

### 运行验收目标

普通内容页任意一张主视觉图片中：

- 可见叠图文字层数 ≤ 2；
- 单层推荐 ≤ 16个汉字；
- 不允许出现大面积正文覆盖人物、建筑、月亮、山体等视觉主体。

---

## 2.3 图片优先原生直出

全站大图默认：

- 优先原色 / 原亮度展示；
- 尽量使用全宽或接近全宽构图；
- 不得使用大面积统一 `rgba()` 遮罩；
- 不得为了托字对整张图使用明显 `backdrop-filter: blur(...)`；
- 不得出现肉眼可见的大块灰蒙 / 毛玻璃文字板覆盖画面主体。

允许：

- 极轻的局部边缘渐变；
- 底部 10%～18% 的轻微暗角用于极短标题；
- 为保证白字可读性使用非常局部的 text-shadow；

但最终肉眼效果必须仍然是：

> **先看到图片本身，而不是先看到一层蒙版。**

# 4. 全站 Text Safe Zone（文字安全区）机制

用户已发现不仅站点页，其他页面也存在“背景动态元素与文字撞色”的问题。

因此必须建立统一 `Text Safe Zone` 思路。

## 4.1 适用范围

至少覆盖：

- 首页主文案区；
- 东坡人生实验题目 / 提示区；
- 人生星河标题和节点说明；
- 站点页正文；
- 今日东坡正文；
- 作品详情正文；
- 分享页控制区。

## 4.2 规则

正文区域内：

1. 粒子亮度 / opacity 自动降级；
2. 大型发光圆斑不得穿过核心文字；
3. WebGL / Canvas高亮点不得停留在正文后方形成低对比；
4. 背景若为复杂图片，正文必须移出图片，而不是继续增强遮罩；
5. 动态粒子可以从正文区域边缘经过，但不得在正文笔画区域形成持续闪烁。

### 推荐实现

可通过以下任一或组合方式实现：

- 给正文区域注册 `data-text-safe-zone`；
- Effects层读取安全区 bbox 并降低该区域粒子透明度；
- 使用 CSS mask / radial attenuation；
- 特效层在正文区降低 alpha；

但不得简单在正文后面重新铺一块大灰色矩形解决问题。

# 5. 全站文字色收口

深色页面默认主文字体系压缩为三层：

1. **一级标题 / 正文主字：暖白 / 米白**
2. **核心强调 / 卷标题：古金**
3. **辅助信息 / 年代 / 提示：青灰 / 浅青**

### 禁止

- 在复杂照片区域使用深蓝文字；
- 同屏无必要同时出现5～6种文字颜色；
- 浅青字叠在浅灰天空 / 月光 / 雾气上；
- 金字叠在高亮灯火 / 金色月光上而无对比保障。

### 对比度门槛

普通正文：建议达到 WCAG AA 级别的可读性目标（常规字号建议 ≥ 4.5:1）。

大标题可适当降低，但肉眼必须在真机亮度50%～80%环境下清晰识别。
