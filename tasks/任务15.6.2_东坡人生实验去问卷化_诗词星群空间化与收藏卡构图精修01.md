# 三、P0-A：东坡人生实验彻底去问卷化

## 3.1 顶部名称统一

当前页面内容已改为“东坡人生实验”，但App Header仍显示“人生问答”。

必须统一：

- Header标题：`东坡人生实验` 或在空间不足时使用 `人生实验`；
- 禁止继续显示“人生问答”“第X题/共X题”等传统问卷措辞；
- 七星进度继续保留。

## 3.2 默认首屏只展示“游戏”，不展示传统答案卡

当前截图中，上方虽然已有中心心识星、目标星与拖拽场景，但下方默认同时铺开多个大矩形说明卡，视觉上仍像传统选择题。

必须改成：

```text
当前实验标题
→ 互动舞台
→ 星体/轨迹/引力/碰撞/聚合等操作
→ 操作完成
→ 自动进入下一幕
```

正常模式下，不允许在互动舞台下方默认连续展示4个大矩形“答案卡”。

## 3.3 Fallback保留但降级为辅助入口

点击式Fallback必须保留，但不得与主玩法同层竞争。

推荐模式：

```text
操作不便？轻触选择
```

用户点击后，再展开：

- 2~4个紧凑目标；
- 或直接点击场景中的目标星完成；
- 展开层应明显小于当前传统答案卡高度。

Low / reduced-motion / 触控失败时可以自动启用点击Fallback，但视觉仍应保持“星体选择”而非“A/B/C/D卡片”。

## 3.4 清理系统Emoji

当前实验页出现 `❄️`、`☁️`、`♨️` 等系统Emoji，与全站水墨星轨体系严重不统一。

必须：

- 禁止在核心实验星体使用系统Emoji；
- 统一改成本地SVG / CSS绘制 / Canvas矢量符号；
- 保证Android、iOS、Chrome 61显示一致；
- 图标风格统一为月白、古金、青蓝、星轨线性/抽象符号。

示例：

- 寒语星：冰裂纹/冷蓝碎星；
- 倦怠星：低亮雾星/下沉光环；
- 变轨释怀：轨道重新展开；
- 骤变星：偏转轨迹+闪光；
- 阻滞星：双环阻尼轨迹。

## 3.5 右侧巨型月亮退居背景

当前右侧月亮面积过大并被裁切，视觉上压过实际互动星体。

必须：

- 缩小20%~35%；
- 降低对比度/亮度；
- 不遮挡题干与目标星；
- 作为空间背景，不得成为当前实验第一视觉中心。

## 3.6 七幕玩法保持差异化

至少确保七幕不是“换文案的同一个拖拽模板”。

必须体现：

1. 星体靠近：靠近/保持距离；
2. 行星撞击：避开/变轨/迎面应对；
3. 星体聚合：多星拖拽合并；
4. 星体分裂：整体拆分/释放；
5. 引力选择：多引力场吸附；
6. 星轨穿越：绕行/穿越/等待；
7. 漂流星救援：牵引他星与自我目标权衡。

允许底层评分继续映射既有模型，但前台必须让用户明显感知玩法变化。

## 3.7 动效反馈

每幕至少提供：

- 拖拽轨迹；
- 接近吸附；
- 碰撞闪光/水墨涟漪；
- 聚合光环；
- 分裂粒子；
- 成功定格0.3~0.8秒；
- 自动进入下一幕。

不得为了动效牺牲Chrome 61与Low/Fallback模式。

# 四、P0-B：诗词星群必须从“列表”变成真正空间星群

## 4.1 当前问题

当前黄州站第三章虽有：

- “精神星核”；
- “本诗词星群”；
- 作品数量；

但实际主要结构仍是：

```text
《初到黄州》  [矩形卡]
《赤壁赋》    [矩形卡]
《念奴娇》    [矩形卡]
……
```

这仍然是列表，不是星群。

## 4.2 必须实现空间化星群

第三章首屏必须直接呈现一个真实可视化星群：

- 中央精神星核；
- 3~7颗作品星；
- 作品星大小不同；
- 亮度不同；
- 与星核通过轨迹、引力线或星尘关联；
- 主作品明显更大；
- 次作品围绕分布；
- 不允许所有作品纵向等宽排列。

黄州示意：

```text
              《念奴娇·赤壁怀古》
                      ✦

      《赤壁赋》  ✦      ✦ 《定风波》
                  \      /
                    ◉
                黄州精神星核
                  /      \
       ✦《卜算子》       《临江仙》✦
```

实际排布不要求照抄，但必须形成空间关系。

## 4.3 交互

点击作品星：

- 星体短暂放大/点亮；
- 显示作品名与一句短提示；
- 再进入作品详情，或点击一次直接进入；
- 必须复用现有Router/historyStack。

## 4.4 小屏兼容

320~480宽度下均要可用。

允许：

- 缩小轨道；
- 轻微错位；
- 星群内部局部横向/纵向延展；

但禁止重新降级成普通纵向列表。

## 4.5 长列表只允许作为次级入口

如果某站作品超过星群一次容纳量，可以在星群下方保留：

> `查看本站全部作品 · 7篇`

点击后进入全部作品列表。

**主视图必须先是星群，列表只能是次级信息。**

# 五、P0-C：今日东坡与三类Canvas卡达到“收藏级”构图

## 5.1 今日东坡页面去“卡中卡”

当前今日东坡页面仍有明显：

```text
页面背景
→ 大米白装裱框
→ 内部真正3:4深蓝诗签
```

形成第二层容器感。

必须：

- 大幅减薄或取消外层米白装裱框；
- 3:4诗签本体直接成为页面第一视觉中心；
- 卡片宽度在390主验收尺寸约88%~94%；
- 页面其余内容退居下方，不与诗签竞争。

## 5.2 日期区域叠层异常核查

真实截图中日期区出现明显灰色半透明大块、红色数字叠层疑似异常。

必须确认：

- 若是动效截图瞬态，重新设计保证任何帧都不产生“重影像Bug”的观感；
- 若是CSS/Canvas重叠，必须修复；
- 日期、节气、签型标记不遮挡；
- 320~480宽度均不叠字。

## 5.3 三类Canvas卡重新定义内部网格

三类：

- `station_result`
- `daily_sign`
- `station_node`

共同问题：上半部场景较丰富，下半部深蓝留白过大，文字偏小，构图上重下轻。

必须重新分配纵向空间。建议参考：

```text
场景/封面       28%~32%
主诗句/主题      18%~22%
核心解释         18%~22%
今日行动/当代启发 12%~16%
站点/作品关联     8%~12%
品牌/说明/留白    8%~12%
```

具体比例可微调，但禁止再出现底部40%左右几乎为空的情况。

## 5.4 字号和阅读性

预览放大后，卡片内次级正文仍偏小。

要求：

- 390宽屏幕预览时核心正文肉眼可直接阅读；
- 主诗句必须是第一文字视觉；
- 次级说明不要缩成“版权脚注感”；
- 免责声明和品牌落款可以小，但不得占据大片空白。

## 5.5 三类卡必须有明显差异

不能只是换标题/图片。

### 人生站点卡
重点：
- 站点场景；
- 人生阶段；
- 代表诗句；
- 当代启发；
- 本站微行动。

### 今日东坡签
重点：
- 当天诗句；
- 日期/节气；
- “放到今天”；
- “今天只做一件小事”；
- 收藏感最强。

### 人生节点卡
重点：
- 人生节点；
- 关键词；
- 代表作品/精神母题；
- 当代启发；
- 生活践行。

三类卡必须一眼能看出用途不同。
