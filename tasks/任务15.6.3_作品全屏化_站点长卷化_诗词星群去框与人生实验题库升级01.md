## 一、任务背景

任务15.6.2已经完成东坡人生实验去问卷化、诗词星群空间化与收藏卡构图精修，整体完成度明显提升。但基于真实手机截图人工复验，仍有四类结构性问题阻碍产品从“约80%~85%完成度”进一步逼近目标效果图90%：

1. **卡片类页面仍然是“缩放预览”，不是全屏作品舞台**，卡片本体图片占比偏小，视觉张力不足；
2. **东坡站点页内容仍然偏卡片列表式**，且部分背景高亮区域、粒子或浅色块与正文叠加，影响可读性；
3. **诗词星群虽然已空间化，但仍存在过多边框与弹出框**，默认框、星核框、点击气泡同时出现，视觉复杂；
4. **东坡人生实验的目标星语义仍偏抽象，且固定7幕缺乏复玩性**，需要升级为“题库 + 分层随机抽取”。

本任务不是继续堆叠光效、圆角、粒子，而是解决“框太多、卡片太小、页面太像H5、实验题型固定”等根本性问题。

# 三、P0-A：卡片类页面真正全屏作品化

## 3.1 适用页面

至少覆盖：

- 今日东坡主诗签；
- 卡片预览页：人生站点卡；
- 卡片预览页：今日东坡签；
- 卡片预览页：人生节点卡。

## 3.2 全屏舞台要求

当前问题是“3:4卡片缩放摆在页面中央，四周仍有明显空白”。整改后要求：

1. 除小红书原生顶部区域、必要Tab和安全区外，海报必须尽可能占满可用视口；
2. 在390×844主流视口中：
   - 卡片宽度目标：可用内容宽度的 **95%~98%**；
   - 不得再出现明显的二次外框或大面积装裱边距；
   - 页面首屏至少展示卡片主要内容80%以上；
3. 顶部三卡型Tab保持轻量，不扩大为大容器；
4. 发布/保存继续采用小型悬浮按钮，不得反客为主；
5. 不新增“换卡”按钮；
6. 预览、保存、发布必须继续严格使用同一个Canvas DataURL。

## 3.3 Canvas内部构图重做

不能只放大外部预览，必须同步重构卡片本体：

### 图片区域
- 图片应成为卡片第一视觉之一；
- 场景图/人物图/山水图建议占整个3:4卡面的 **40%~48%**；
- 避免当前“图片约1/3 + 大白诗句框 + 深蓝正文”的模板感；
- 图片可采用顶部大图、沉浸式半屏图、渐隐叠字等方式，但不得降低正文可读性。

### 文本层级
必须形成清晰视觉排序：

```text
1. 场景图 / 主诗句
2. 作品出处 / 站点身份
3. 当代解读
4. 微行动
5. 品牌落款 / 免责声明
```

### 视觉原则
- 降低“大块纯白矩形诗句框”占比；
- 允许采用宣纸渐隐、半透明纸笺、局部留白而不是整块白框；
- 下半部禁止再出现大面积无信息深蓝空区；
- 每类卡片必须有明显不同的视觉重心，不能只是文字内容不同。

## 3.4 今日东坡特别要求

今日东坡必须像“每日收藏作品”，而不是“页面内一张卡”：

- 主诗签直接成为第一视觉；
- 删除多余包裹层；
- 日期、节气、诗签印章与图片融为一体；
- 进入页面后第一眼必须有“想保存”的感觉；
- 下方延展内容不得抢夺主诗签视觉中心。

# 四、P0-B：东坡站点页从卡片列表改造成沉浸式人生长卷

## 4.1 当前问题

当前站点页虽然Hero较好，但正文仍存在：

- 第一幕、第二幕、第四幕、第五幕等连续大圆角卡片；
- 背景月轮、星点、粒子、高亮色块穿过正文；
- 浅底浅字或亮点与文字重叠导致可读性下降；
- 页面整体仍然像“若干知识卡片纵向堆叠”。

## 4.2 新结构：人生长卷

站点页Hero之后，必须按“一段旅行”而不是“卡片清单”组织：

```text
站点Hero
  ↓
历史现场 · 时间轨迹
  ↓
代表名句 · 大场景/大纸笺
  ↓
生活片段 · 星轨脉络
  ↓
诗词星群 · 空间星空
  ↓
现代启发 · 低干扰阅读区
  ↓
今日行动 · 轻量行动区
  ↓
生成本站人生卡 / 返回人生星河
```

各段必须使用不同构图，不得出现“6张同类卡片连续排列”。

## 4.3 六种内容表达建议

### A. 历史现场：时间轨迹
- 以年份、地点、事件沿纵向/斜向轨迹展开；
- 时间点配小型场景缩略图或星点；
- 不使用完整大卡片包裹。

### B. 代表名句：场景主视觉
- 允许一张横跨内容区的大场景图；
- 名句直接叠加在安全高对比区域，或用局部纸笺承托；
- 不再用大白矩形框占据半屏。

### C. 生活片段：生活星轨
- 把人物、经历、事件作为沿轨道排列的生活节点；
- 每个节点只呈现短句，点击或展开再看详情。

### D. 诗词星群
- 使用第五章要求的去框化真实星空。

### E. 现代启发
- 允许保留一个阅读型纸笺，但必须是本屏唯一主容器；
- 不允许背景高亮粒子穿过正文。

### F. 今日行动
- 不做大卡片；
- 可做“行动星点 / 小纸签 / 一句行动”并配轻量完成态。

## 4.4 可读性硬门禁

正文区域必须满足：

1. 文字背后不得穿过高亮大月轮、强光星点、发光轨迹；
2. 高亮粒子不得与正文重叠到影响识别；
3. 正文区背景对比度必须稳定；
4. 浅色背景必须搭配深色正文，深色背景必须搭配高对比暖白/月白；
5. 任何截图中不得再出现“文字因背景色相近而看不清”的情况；
6. 所有站点（至少9站）都要抽样检查，不得只验证黄州/密州。

## 4.5 长页面导航

Cosmic Dock保持，但允许优化长阅读体验：

- 向下阅读时可缩为极简态；
- 上滑、接近章节切换或页面底部时恢复；
- 不得影响首页/人生星河/今日东坡的主导航识别；
- 若本轮实现风险过高，可列P1，但不得破坏现有稳定Dock。

# 五、P0-C：诗词星群彻底去框化

## 5.1 当前问题

当前诗词星群已经有空间布局，但仍存在：

- 外层大框；
- 星图内部框；
- 精神星核矩形框；
- 点击作品星后又弹出大矩形框；
- 多层边框同时存在，导致界面像“星图组件”，不是真正的星空。

## 5.2 新原则

> **默认状态只允许看到：背景、轨道、精神星核、作品星、作品名。**

必须删除/弱化：

- 中央精神星核外的大矩形框；
- 不必要的星图内框；
- 大面积包裹边框；
- 点击后遮挡星群的大卡片。

## 5.3 默认星群状态

必须包含：

- 中央精神星核；
- 5~8颗代表作品星；
- 星体大小、亮度、光晕有层级；
- 轨道/引力线轻量存在；
- 作品名靠近星体，避免文字与其他星体重叠；
- 空间上留有足够“黑场/夜空”，不把所有区域填满。

## 5.4 点击作品星后的反馈

禁止再弹出当前这种大矩形卡。

改为：

1. 被点击作品星放大10%~18%；
2. 光晕增强、其他星轻微降亮；
3. 星旁浮出轻量信息条/气泡，仅包含：
   - 作品名；
   - 一句金句或类型；
   - “进入作品”轻入口；
4. 信息气泡面积不得超过星群舞台的20%；
5. 点击空白处或其他星自动切换/关闭；
6. 320px窄屏不能遮挡中心星核或大量作品星。

## 5.5 全部作品入口

“展开本站全部收录作品”可保留，但必须是次级入口；默认首屏重点仍是星群，而不是列表。

# 六、P0-D：东坡人生实验升级为题库 + 分层随机抽取

## 6.1 目标星增加短提示

当前“骤变星、阻滞星、寒语星、倦怠星”等仅有名词，用户理解成本偏高。

每颗目标星必须增加 **4~10字的极短语义提示**，直接绑定星体显示，例如：

```text
骤变星
突然发生变化

阻滞星
努力却没进展

寒语星
被一句话刺到

倦怠星
什么都不想做
```

要求：

- 提示不得变成长段选项；
- 不重新回到A/B/C/D问卷；
- 可采用星名下小字、环绕小字、星旁浮签；
- 目标星仍然是交互主体。

## 6.2 建立实验题库

从固定7幕升级为题库模式。

### 题库规模
V1建议至少：

- **18~24个实验场景**；
- 每次实际体验仍抽取 **7幕**，控制总时长；
- 后续可扩展，不要写死在视图DOM中。

### 题目分类
至少覆盖以下维度：

1. 突发变化 / 风险应对；
2. 压力与承受；
3. 人际关系与评价；
4. 行动方式 / 拖延 / 坚持；
5. 自我调节与独处；
6. 关系、责任与共情；
7. 选择、取舍与资源分配；
8. 失败后恢复；
9. 成就与外界认可；
10. 安稳与探索。

## 6.3 分层随机抽样

禁止简单 `Math.random()` 从所有题目直接抽7题。

必须保证一次实验中核心维度覆盖均衡：

- 7幕至少覆盖7个不同维度或主要维度；
- 同类题型不得连续大量出现；
- 拖拽、碰撞、聚合、分裂、轨道选择、引力选择、救援等交互形式也要尽量错开；
- 结果映射仍兼容8心境 + 9站点评分模型。

## 6.4 Session Seed

一次实验开始后生成session seed：

- 本次7题顺序固定；
- 刷新/视图重绘不能中途换题；
- 用户点击“重新实验”时才重新抽取；
- 可记录seed用于测试复现；
- 不要求持久化到服务器。

## 6.5 数据结构

建议将实验题库从视图逻辑中抽离，结构至少包含：

```js
{
  id,
  dimension,
  interactionType,
  title,
  instruction,
  targets: [
    {
      id,
      name,
      hint,
      scoreVector
    }
  ]
}
```

不得在 `views.js` 中继续大段硬编码每题DOM与文本。

## 6.6 Fallback

原“操作不便？轻触选择”折叠式Fallback继续保留：

- 默认收起；
- 文案与本题目标星同步；
- 低性能/触控异常仍可完成7幕；
- Fallback选项与拖拽结果必须映射到同一评分向量。
