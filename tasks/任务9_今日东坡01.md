> **一句东坡诗词 + 一段真实背景 + 一句东坡式理解 + 一个今日小行动。**

## 三、每日内容机制

### 3.1 稳定映射

同一自然日、同一版本数据应稳定得到同一条内容。

可采用：

- 日期序号 `% 内容总数`；
- 稳定日期哈希；
- 预设日期表。

不得每次刷新随机抽取。

### 3.2 时区

使用稳定的本地日期逻辑，避免 UTC 切日导致中国用户晚间提前切换。

不得为了“获得准确服务器时间”发起网络请求。

如容器日期异常，应有稳定本地降级策略并记录。

### 3.3 内容结构

完整逻辑视图至少包含：

- 今日日期；
- 今日诗句；
- 作品名；
- 真实背景；
- “今天可以这样理解”；
- 今日小行动；
- 关联人生站点入口；
- 生成“今日东坡签”入口。

## 四、首页预览

首页只展示：

- 今日诗句；
- 一句短理解；
- `坐一会儿` 入口。

首页与 Daily 必须消费同一条离线数据结果。

## 五、内容体验

主题应有变化，包括：

- 风雨与徐行；
- 明月与思念；
- 山水与出游；
- 好好吃饭；
- 友情；
- 家人；
- 读书；
- 人生转弯；
- 做事；
- 休息；
- 接受不完美；
- 日常小快乐。

不应每天都是“别焦虑”。

## 六、今日小行动

必须：

- 低风险；
- 低成本；
- 5—20 分钟大多可完成；
- 不依赖购买商品；
- 不承担治疗承诺；
- 不羞辱用户；
- 不要求公开隐私。

## 七、Skill 1.6.0 工程要求

- 今日数据完全本地；
- 禁止 fetch/XHR 获取日期内容；
- Daily 是同一 H5 内逻辑视图；
- JS 为 Classic Script / ES2017 / Chrome 61；
- 不使用 ESM、内联 JS、在线字体/图片；
- 日期哈希函数必须是本地确定性实现；
- 分享卡入口只传数据给任务10，不直接调用 Native Bridge；
- 关键 CSS 有 Chrome 61 回退。

## 八、异常与降级

必须处理：

- 今日内容记录不存在；
- 引用诗句被撤回审核；
- 日期计算异常；
- 数据为空。

降级到一条已审核默认内容，不空白、不联网补数据。

## 九、Milestone B 门槛

任务4—9完成后必须集中体验：

```text
首页
→ 测试
→ 结果
→ 人生宇宙
→ 作品内容
→ 今日东坡
```

并额外检查：

```text
完全断网
Chrome 61兼容基线
无 ESM/内联JS/禁止API
阶段产物 audit
```

全部主链可运行、可返回、无阻塞错误后才通过 Milestone B。

- 次日可切换；
- 首页预览与完整内容一致；
- 内容来自统一离线数据层；
- 关联站点正确；
- 今日小行动符合安全边界；
- 有分享卡入口；
- 断网状态主链完整；
- Chrome 61 可用；
- 阶段 audit 通过。
