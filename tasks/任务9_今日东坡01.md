# 任务9 今日东坡 0.1

> 项目：苏轼宇宙小红书小工具  
> 阶段：Core Experience  
> 前置任务：任务1—8  
> 任务优先级：P0

## 一、任务目标

实现“今日东坡”高频入口，让产品从一次性测试工具升级为可以每天打开一次的轻量文化陪伴工具。

每日内容固定结构：

**一句东坡诗词 + 一段真实背景 + 一句东坡式理解 + 一个今日小行动。**

## 三、每日内容机制

### 3.1 稳定映射

同一自然日、同一版本数据应稳定得到同一条内容。

可以采用：

- 日期序号 `% 内容总数`；
- 稳定日期哈希；
- 预设日期表。

不得每次刷新随机抽取，造成“今日”内容不断变化。

### 3.2 时区

按平台环境和产品目标选择稳定本地日期逻辑，并在实现中避免 UTC 切日导致中国用户晚间提前切换。

若官方运行环境对时区有特殊约束，应遵循官方规则并记录。

### 3.3 内容结构

完整页至少包含：

- 今日日期；
- 今日诗句；
- 作品名；
- 真实背景；
- “今天可以这样理解”；
- 今日小行动；
- 关联人生站点入口；
- 生成“今日东坡签”入口。

## 四、首页预览

首页只展示：

- 今日诗句；
- 一句短理解；
- `坐一会儿` 入口。

完整内容进入 Daily 页面后再展开。

## 五、内容体验

“今日东坡”不应每天都是“别焦虑”。内容主题应有变化，包括：

- 风雨与徐行；
- 明月与思念；
- 山水与出游；
- 好好吃饭；
- 友情；
- 家人；
- 读书；
- 人生转弯；
- 做事；
- 休息；
- 接受不完美；
- 日常的小快乐。

## 六、今日小行动

行动必须：

- 低风险；
- 低成本；
- 5—20 分钟大多可完成；
- 不依赖购买商品；
- 不承担治疗承诺；
- 不羞辱用户；
- 不要求公开隐私。

## 七、异常与降级

必须处理：

- 今日内容记录不存在；
- 引用诗句被撤回审核；
- 日期计算失败；
- 数据为空。

应降级到一条已审核默认内容，而不是空白页。

## 八、Milestone B 门槛

任务4—9完成后，必须进行 Core Experience 自检：

```text
首页
→ 测试
→ 结果
→ 人生宇宙
→ 作品内容
→ 今日东坡
```

以上链路必须全部可运行、可返回、无阻塞错误，且整体已经能够让真实用户理解产品价值。

## 九、验收标准

- 同日多次打开内容稳定；
- 次日可切换新内容；
- 首页预览与完整页一致；
- 内容来自统一数据层；
- 关联站点正确；
- 今日小行动符合安全与价值边界；
- 有分享卡入口；
- Core Experience 主链路完整。

## 十一、硬性约束

1. 同一天不能因刷新而随机变化。
2. 不把“今日东坡”做成每日鸡汤。
3. 每条诗句和背景都必须可追溯。
4. 现代解读必须与苏轼原文区分。
5. 任务9结束时必须完成一次任务4—9集中体验自检。
