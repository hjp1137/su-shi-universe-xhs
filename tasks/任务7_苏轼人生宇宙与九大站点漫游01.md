## 一、任务目标

实现“苏轼人生宇宙”主漫游逻辑视图，用一条兼具“江河 + 星图 + 时间线”感觉的纵向生命线串联九大人生站点，让用户像漫游一条人生河流一样理解苏轼，而不是阅读普通年表。

## 四、核心视觉

### 4.1 生命线

应体现：

- 江河流动感；
- 星轨/节点感；
- 时间推进；
- 远近层次；
- 月、雾、山、水等东方氛围。

正式实现优先：

```text
DOM + CSS
SVG 路径
Canvas 2D 轻量氛围
```

**V1 禁止以 WebGL/复杂 3D 作为生命线基础。**

### 4.2 站点节点

每个节点至少显示：

- 地点；
- 阶段名称；
- 时间或年龄精简信息；
- 1 个关键词；
- 可点击状态。

当前测试结果对应站点可轻度高亮。

### 4.3 节奏

- 少年与京师：明亮、向上；
- 乌台：压暗、骤雨；
- 黄州：重新出现月色与江水；
- 杭州：更舒展；
- 惠州/儋州：路更远但不绝望；
- 常州：安静收束。

不为每站完全换主题色。

## 五、交互

- 上下滑动浏览九站；
- 点击站点进入详情逻辑视图；
- 当前站点有选中反馈；
- 支持返回之前滚动位置；
- 从结果进入时定位对应站点；
- 可提供“直接去我的站点”。

主要点击/拖动事件优先 Pointer Events。

## 六、站点详情入口

详情接收稳定 `station_id`，由统一数据驱动：

- 真实经历；
- 代表事件；
- 代表作品；
- 代表诗句；
- 东坡式理解；
- 相关站点。

任务7实现基础详情容器，任务8完善内容体验。

## 七、Skill 1.6.0 工程要求

- Universe/Station 均为同一 H5 内逻辑视图；
- 禁止运行时 fetch/XHR；
- JS 为 ES2017 / Chrome 61；
- 禁止 ESM/内联 JS；
- 关键 CSS 有 Chrome 61 回退；
- 素材本地化；
- 不一次性加载大量高分辨率图；
- 隐藏视图后停止无意义 Canvas/定时器；
- 不新增 WebGL。

## 八、性能要求

- 滚动顺畅；
- 不因粒子掉帧；
- 动效低频、可降级；
- 页面离开后清理动画；
- 资源大小纳入 ZIP 预算；
- 低端设备优先稳定。

## 九、非目标

不做：

- 地理地图；
- 人物关系图谱；
- WebGL 星球；
- 完整年谱；
- 全部作品时间轴。

## 十、验收标准

- 九站全部显示且顺序正确；
- 从结果可定位指定站点；
- 点击节点可打开详情；
- 返回保留合理浏览位置；
- 有“江河/宇宙漫游”体验而非普通列表；
- Chrome 61 下布局与交互可用；
- 无网络/ESM/内联 JS；
- 无 WebGL 依赖；
- 所有节点来自统一数据层；
- 阶段 audit 无新增阻塞。
