# 任务4 首页与核心入口体验 0.1

> 项目：苏轼宇宙小红书小工具  
> 阶段：Core Experience  
> 前置任务：任务1—3  
> 任务优先级：P0

## 一、任务目标

实现小工具正式首页，让用户第一次进入后 3 秒内理解产品不是“苏轼百科”，而是一个“从苏轼人生和诗词中寻找当下生活启发”的互动工具。

首页必须以用户当下为起点，以“测一测、逛一逛、坐一会”三条路径组织体验。

## 三、首页结构

### 3.1 第一屏

必须包含：

- 项目名：`苏轼宇宙`；
- 核心 Slogan：`遇到烦心事，先去东坡那里坐一会儿。`；
- 一句轻量辅助说明；
- 第一主按钮：`看看我的人生正在东坡哪一站`；
- 今日东坡一句诗的轻预览。

第一屏禁止从“苏轼，字子瞻……”等百科简介开始。

### 3.2 三大入口

建立三条清晰路径：

1. **测一测｜我的东坡人生站点** → Quiz；
2. **逛一逛｜苏轼人生宇宙** → Universe；
3. **坐一会｜今日东坡** → Daily。

三者视觉层级要有主次：测试为第一核心入口，宇宙与今日东坡为次入口。

### 3.3 首页氛围

首页需要体现：

- 夜色 / 深靛蓝；
- 月光；
- 水面或江流感；
- 微弱星点；
- 少量烟火暖色；
- 大量呼吸空间。

动效轻微即可，不能做持续抢眼的粒子秀。

### 3.4 今日东坡预览

从 `daily-dongpo` 数据读取当天稳定内容，至少显示：

- 一句诗；
- 一句非常短的理解；
- `坐一会儿` / `看看今日东坡` 入口。

刷新页面后，同一天内容不得无规则随机变化。

### 3.5 最近结果（可选）

若平台允许安全的本地持久化，可显示最近一次人生站点结果；如果官方环境不适合持久化，则优雅省略，不得为了该功能引入不可靠方案。

## 四、交互要求

- 主 CTA 一屏可见；
- 主要入口点击区域明确；
- 首屏不堆过多说明；
- 滚动层级简单；
- 返回首页时不出现状态错乱；
- 页面打开无明显白屏闪烁；
- 用户无需阅读教程即可开始。

## 五、非目标

本任务不实现测试题内部逻辑，不实现完整人生宇宙时间线，不实现完整今日东坡详情，不实现分享卡。

## 六、验收标准

### 产品

随机让一名未看设计文档的用户看首页 3 秒，应能大致回答：

- 这是关于苏轼的；
- 可以测自己处于苏轼人生哪一站；
- 整体气质是温和、正向、非教辅式。

### 视觉

- 符合现代水墨 × 深靛蓝规范；
- 不像普通古诗词网站；
- 不像活动 H5 模板；
- 不依赖密集文字撑内容。

### 工程

- 三大入口均能进入对应占位或正式页面；
- 今日东坡预览来自数据层；
- 无硬编码重复数据；
- 官方 Skill 校验无新增阻塞问题。

## 八、硬性约束

1. 首页第一屏必须先连接用户，而不是先介绍苏轼。
2. 不允许堆满作品列表、朝代标签、百科卡片。
3. 核心按钮文案应自然、有邀请感，不做焦虑营销。
4. 视觉必须服从阅读与点击效率。
