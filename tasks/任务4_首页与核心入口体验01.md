## 一、任务目标

实现小工具正式首页，让用户第一次进入后 3 秒内理解产品不是“苏轼百科”，而是一个“从苏轼人生和诗词中寻找当下生活启发”的互动工具。

首页必须以用户当下为起点，以“测一测、逛一逛、坐一会”三条路径组织体验。

## 三、首页结构

### 3.1 第一屏

必须包含：

- 项目名：`苏轼宇宙`；
- 核心 Slogan：`遇到烦心事，先去东坡那里坐一会儿。`；
- 一句轻量辅助说明；
- 第一主按钮：`看看我的人生正在东坡哪一站`；
- 今日东坡一句诗的轻预览。

第一屏禁止从“苏轼，字子瞻……”等百科简介开始。

### 3.2 三大入口

建立三条清晰路径：

1. **测一测｜我的东坡人生站点** → Quiz；
2. **逛一逛｜苏轼人生宇宙** → Universe；
3. **坐一会｜今日东坡** → Daily。

这里的 Home/Quiz/Universe/Daily 均为同一离线 H5 内的逻辑视图，不是传统小程序 Page。

### 3.3 首页氛围

首页需要体现：

- 夜色 / 深靛蓝；
- 月光；
- 水面或江流感；
- 微弱星点；
- 少量烟火暖色；
- 大量呼吸空间。

实现优先 CSS/SVG/Canvas 2D；V1 不使用 WebGL。动效轻微，不能做持续抢眼粒子秀。

### 3.4 今日东坡预览

从任务2的本地数据层读取当天稳定内容，至少显示：

- 一句诗；
- 一句非常短的理解；
- `坐一会儿` / `看看今日东坡` 入口。

**不得通过 fetch/XHR 加载本地 JSON。** 应消费任务2已经验证的 Offline H5 数据装载层。

### 3.5 最近结果（可选）

可使用 Skill 允许的本地存储能力；存储不可用时优雅省略，不得影响主链。

## 四、Skill 1.6.0 工程要求

- 所有点击通过 `addEventListener`，禁止 `onclick=`；
- JS 为 Classic Script / ES2017 / Chrome 61；
- 不使用 `type="module"`；
- 不引入 CDN、在线字体或远程背景图；
- 关键 CSS 必须有 Chrome 61 回退；
- 安全区沿用任务3双兼容方案；
- 首屏资源尽量轻，不为了 Hero 引入大 PNG/视频；
- 新增资源必须记录大小。

## 五、交互要求

- 主 CTA 一屏可见；
- 主要入口点击区域明确；
- 首屏不堆过多说明；
- 滚动层级简单；
- 返回首页时状态稳定；
- 页面打开无明显白屏闪烁；
- 用户无需教程即可开始。

## 六、非目标

本任务不实现测试题内部逻辑，不实现完整人生宇宙时间线，不实现完整今日东坡详情，不实现分享卡。

## 七、验收标准

### 产品

未看设计文档的用户看首页 3 秒，应大致知道：

- 这是关于苏轼的；
- 可以测自己处于苏轼人生哪一站；
- 气质温和、正向、非教辅式。

### 视觉

- 符合现代水墨 × 深靛蓝；
- 不像普通古诗词网站；
- 不像活动 H5 模板；
- 不依赖密集文字撑内容。

### 工程

- 三大入口进入对应逻辑视图；
- 今日东坡预览来自统一离线数据层；
- 无运行时 fetch/XHR；
- 无内联 JS/ESM；
- Chrome 61 关键样式成立；
- 新增资源不造成明显包体失控；
- 官方阶段性 audit 无新增阻塞问题。

## 九、硬性约束

1. 首页第一屏必须先连接用户，而不是先介绍苏轼。
2. 不允许堆满作品列表、朝代标签、百科卡片。
3. 核心按钮文案自然、有邀请感，不做焦虑营销。
4. 视觉服从阅读与点击效率。
5. 不得突破任务1.1确立的离线/CSP/Chrome 61工程基线。
