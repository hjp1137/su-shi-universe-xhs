# 三、P1-A：今日东坡诗句区排版校正

## 3.1 当前已确认根因

当前今日东坡诗句区域仍受旧 `.daily-poetry-slip` 样式影响，其历史规则包含类似：

```css
min-height: 380px;
display: flex;
flex-direction: column;
justify-content: space-between;
max-width: 340px;
```

导致：

- 诗句、出处、日期被强制拉开到上/中/下；
- 短诗本可一行显示却被340px宽度限制挤成两行；
- 页面出现大量无意义纵向空白；
- 内容节奏不像诗签，而像三个互不相关的模块。

## 3.2 必须整改

新的今日东坡 Hero 诗句区不得继续继承旧诗签布局。

应改为正常内容流：

```text
“小舟从此逝，江海寄余生。”
《临江仙·夜归临皋》 · 黄州
2026年9月8日 · 秋 · 今日小笺
```

要求：

- 三层内容连续排列；
- 垂直间距建议 8～14px；
- 不使用 `space-between`；
- 不使用固定 `min-height:380px`；
- 不再以340px限制整个诗句区；
- 短诗优先单行展示。

## 3.3 短诗单行策略

在 390px 设备宽度下，对于类似：

> “小舟从此逝，江海寄余生。”

这种长度的句子，必须优先单行。

可按优先级调整：

1. 放宽有效宽度；
2. 略减 letter-spacing；
3. 在不低于视觉可读阈值的前提下微调字号；
4. 最后才允许换行。

不得通过把字体缩得很小来硬塞一行。

## 3.4 全站排查

搜索并检查：

- `min-height` + `space-between` 的旧诗签/卡片样式；
- 因历史 class 复用导致的布局串扰；
- 短标题/短诗被无意义强制换行；
- 文字区存在大块空白但内容被人为拉散。

重点检查：

- 今日东坡；
- 结果页；
- 站点详情；
- 卡片预览顶部 tab 区；
- 分享卡内部文案布局。

# 四、P1-B：三类 Canvas 海报重新建立字号标尺

## 4.1 当前问题

Canvas 原图尺寸为：

> `750 × 1000`

但手机390宽预览时，实际海报宽约 386px，缩放比例约：

> `386 / 750 ≈ 0.515`

因此 Canvas 内部：

- 12px → 手机视觉约 6.2px
- 14px → 手机视觉约 7.2px
- 16px → 手机视觉约 8.2px

当前三类分享卡大量使用 12～16px 字号，导致实际预览明显看不清。

## 4.2 新字号硬基线

不得再照搬网页 CSS 字号进入 Canvas。

建议 750px Canvas 内部基线：

| 文本层级 | Canvas 建议字号 | 390px预览目标 |
|---|---:|---:|
| 主标题/站点名 | 42～52px | 21～27px |
| 核心诗句 | 36～46px | 18～24px |
| 二级标题 | 28～34px | 14～18px |
| 正文 | **26～30px** | **13～16px** |
| 辅助信息 | 22～26px | 11～14px |
| 极次要版权 | 18～20px | 9～10px |

除极次要版权外：

> **禁止再出现 12～16px Canvas 主体文字。**

## 4.3 实际像素验收

在真实浏览器 390px 宽环境下：

- 站名、诗句必须无需放大即可读；
- 正文视觉字号目标 ≥ 13px；
- 辅助信息目标 ≥ 11px；
- 不允许依赖系统截图放大才能辨认。

# 六、P1-D：全站粒子视觉降噪

## 6.1 当前问题

当前多个场景仍使用较大的 `THREE.PointsMaterial`：

- Hero：size≈0.08 / opacity≈0.6
- Result：size≈0.10 / opacity≈0.8
- Universe：size≈0.12 / opacity≈0.75

默认点精灵为明显方点，实际运行呈现大量：

> `■ ■ ■`

对正文阅读产生明显干扰。

## 6.2 新原则

> **粒子应该“能感觉到，但第一眼注意不到”。**

建议总体范围：

- `size`: 0.04～0.065
- `opacity`: 0.25～0.45

不同页面按阅读密度进一步降低。

## 6.3 柔化形态

优先方案：

- 使用本地极小圆形/柔光点纹理作为 `PointsMaterial.map`；
- 中心微亮、边缘透明；
- 禁止远看仍像硬方块。

如果因包体/兼容性不采用贴图，则至少通过：

- 降低 size；
- 降低 opacity；
- 减少点数量；

消除方块感。

禁止新增：

- CDN；
- runtime fetch；
- Worker；
- WASM；
- 远程纹理。

## 6.4 Text Safe Zone 真正生效

正文区域背后的特效必须主动退让，而不是只给文字加阴影。

要求：

- 正文区域粒子透明度降低 50%～70%；
- 高亮光斑不得穿过大段正文；
- 大型 halo 不得与正文主体重叠形成低对比区；
- 页面滚动进入正文区域时，粒子应弱化；
- 分享卡预览页面的背景粒子强度进一步降低。

重点检查：

- 东坡站点；
- 站点详情；
- 今日东坡；
- Result；
- 人生星河；
- 卡片预览。
