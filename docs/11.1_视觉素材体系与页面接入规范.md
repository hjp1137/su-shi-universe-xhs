# 视觉素材体系与页面接入规范 1.0

> 项目：苏轼宇宙小红书小工具 (su-shi-universe-xhs)  
> 版本：Visual 2.0 / Art Asset Integration  
> 对应任务：任务 15.3 高质量视觉素材接入与诗词宇宙页面深度美化 0.1  
> 规范基线：Chrome 61 / ES2017 / Skill 1.6.0 Classic Script / 纯离线无外链  

---

## 一、规范背景与目标

在完成 Visual 2.0 视觉底层、Three.js 东方水墨宇宙粒子星轨以及全站动效交互细节后，苏轼宇宙项目正式引入项目组统一规划制作的高质量美术视觉资产。

本规范旨在统一人工美术资产与程序化前端工程的结合基准，确立 **“Three.js 负责空间动势、图片素材负责画面质感、DOM 负责内容与无障碍交互”** 的三层协同架构，杜绝散落硬编码与风格漂移，确保移动端体验达到宣传效果图级别的“现代水墨 × 深靛蓝 × 月色江水 × 东方诗词宇宙”质感。

## 四、统一服务与数据接口规范

严禁在各逻辑视图内散落硬编码图片绝对或相对路径。统一通过 `SuShiUniverse.ArtAssets`（定义于 `js/art-assets.js`）访问：

### 4.1 接口清单

```javascript
// 1. 首页 Hero
var heroUrl = SuShiUniverse.ArtAssets.homeHero;

// 2. 宇宙体系素材
var planetPrimary = SuShiUniverse.ArtAssets.cosmos.planetPrimary;
var moonHalo = SuShiUniverse.ArtAssets.cosmos.moonHalo;

// 3. 安全获取站点场景图（支持别名容错与黄州回退）
var sceneUrl = SuShiUniverse.ArtAssets.getStationScene(stationId);

// 4. 安全获取重点诗词场景图（无专属图返回 null，由上层优雅降级）
var poemUrl = SuShiUniverse.ArtAssets.getPoemScene(workId);

// 5. 装饰素材
var badgeMoon = SuShiUniverse.ArtAssets.decor.badgeMoon;

// 6. 全量素材路径校验辅助
var allPaths = SuShiUniverse.ArtAssets.getAllAssetPaths();
```

### 4.2 数据层双向对齐

`js/art-assets.js` 装载后自动为 `SuShiUniverse.Data.stations` 各站点对象补齐 `scene_image` 属性，确保数据驱动与视图渲染双向无缝透明。

## 五、图片复用、构图与性能降级策略

### 5.1 图片复用规则
1. **一图多用，严禁冗余副本**：9 大站点的场景图 (`station-*.webp`) 同时供“测验结果页”、“人生宇宙长河微缩节点”、“站点详情页 Hero”复用；
2. **重点诗词优雅降级**：非 5 篇重点作品页面，自动回退到其归属站点的场景图，保证视觉风格连贯且无需为每首诗重复占用包体；
3. **CSS 构图自适应**：通过 `object-fit: cover` 与 `object-position: center 25%` 精确控制构图重心，兼顾 320px 至 480px 宽度。

### 5.2 遮罩与可读性法则（内容第一）
- **文字必须高于图片**：所有承载文字的图片容器必须带有 `position: relative; z-index: 1;` 保护；
- **双层渐变暗化**：图片容器上方统一覆盖 `background: linear-gradient(180deg, rgba(14, 24, 48, 0.25) 0%, rgba(14, 24, 48, 0.82) 70%, rgba(14, 24, 48, 0.98) 100%)`；
- **半透明混合**：场景大图透明度控制在 `0.35 ~ 0.40`，饱和度轻微收敛 (`filter: saturate(0.85)`)，融入深靛蓝 (`#0b1326`) 调性。

### 5.3 Fallback 优雅降级策略
1. **图片加载中/失败**：底色保留 CSS 经典靛蓝渐变与宣纸质感阴影，DOM 结构占位稳固，绝对不发生布局抖动或白屏；
2. **无 WebGL 环境**：图片素材与 CSS 水墨渐变完全接管视觉表现，Three.js 降级不影响图片质感与任何核心流程；
3. **极速首屏**：首屏优先加载 `hero-home.webp`，长河微缩图与作品图均伴随路由按需触达。

## 六、禁止行为与开发红线

1. **绝对禁止自行生成图片**：严禁 AI 自行调用生图模型或生成任何未经项目组审核的图片，全量复用正式资产；
2. **绝对禁止风格突变**：严禁混入西式科幻、高饱和卡通或非本案调性的素材；
3. **绝对禁止在图片中烘焙字样**：标题、正文、年代、按钮必须保持为标准 DOM 文本，保障无障碍与多语言扩展性；
4. **绝对禁止外链与远程依赖**：杜绝一切 CDN、第三方图床或未打包外链，保持 100% 本地纯离线单页；
5. **绝对禁止破坏包体隔离**：禁止把 `design-assets/` 源码打入发布包，发布包仅限 `dist/` 纯净运行态。
