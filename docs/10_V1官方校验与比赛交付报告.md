## 五、Chrome 61 / ES2017 / 移动端真机适配结果

1. **Flex Gap 回退保障**：
   - 彻底消除了所有对原生 `gap:` 的唯一依赖；
   - 提供了完备的兄弟选择器（`* + *`）间距支持（`.gap-sm`, `.gap-md`, `.gap-lg`, `.share-card-actions > * + *` 等），确保老核无样式坍塌。
2. **Aspect-Ratio 回退保障**：
   - 媒体海报容器配置 `min-height: 400px;` 基线回退，防未支持 `aspect-ratio` 时高度塌陷。
3. **双安全区兼容**：
   - 全局采用 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))` 双兼容语法，在 PC 模拟器注入变量与真机刘海屏下均完美适配。
4. **系统减弱动效降级**：
   - `@media (prefers-reduced-motion: reduce)` 全局覆盖，低功耗或敏感模式动画归零，保留完整优雅版面。
5. **触控交互防误触**：
   - `touch-action: manipulation` 消除真机 300ms 延迟；
   - `user-select: none;` 杜绝按钮长按选中文本；
   - `overflow-x: hidden;` 彻底杜绝全视图横向晃动。
