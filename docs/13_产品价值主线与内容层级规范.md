# 13 · 产品价值主线与内容层级规范

> 规范版本：1.0.0  
> 生效任务：任务 15.7（产品价值主线与内容层级重构）  
> 适用范围：全站所有视图、卡片、Canvas 分享卡、导航及文案层级

---

## 一、产品北极星

本项目的核心价值与北极星指标统一定义为：

> ### **借苏轼的人生，找到此刻的自己。**

全站不再被理解为单纯的“苏轼生平资料站”、“九站目录”或“诗词可视化合集”。所有页面设计、组件组织、文案表达与交互引导均必须服务于帮助用户获得以下**三项核心收益**：

1. **我现在更像苏轼人生中的哪一站？**（自我对照与定位）
2. **苏轼在类似处境中，是怎样走过来的？**（情感共鸣与历史哲思）
3. **今天我能带走一句什么话、做一件什么小事？**（切实可行的现实抚慰与微行动）

---

## 二、首次体验唯一主线

为了避免用户“初次进入感到丰富但杂乱不知所措”，全站确立**唯一的首次用户体验主线**：

```text
首页 (Home) 
  → 开始东坡人生实验 (Quiz 7幕选择) 
    → 我的东坡答案 (Result 核心收获) 
      → 生成/保存人生卡 (ShareCard 结果外化) 
        → 可选深入探索 (Station / Universe 小宇宙)
```

- **体验时长预算**：2～4 分钟内流畅顺畅走完闭环。
- **首次门禁**：不强制要求首次用户阅读百科史料、浏览诗词星群或通读九站长卷，上述重度内容全部归入“后续主动深入探索”。

---

## 三、核心产品对象：我的东坡答案 (DongpoAnswer)

用户完成东坡人生实验后，系统构建并冻结一个稳定、同源且可复用的核心领域对象 `DongpoAnswer`。

### 3.1 领域对象字段标准

```javascript
DongpoAnswer = {
  stationId: string,         // 站点唯一标识，如 'station_huangzhou'
  stationName: string,       // 完整站点名，如 '黄州'
  stationShortName: string,  // 简明站名，如 '黄州'
  stationTheme: string,      // 人生主题，如 '重生'
  stationOrder: number,      // 站序 (1~9)
  quote: string,             // 代表名句正文
  quoteSource: string,       // 诗作标题出处，如 '《定风波·莫听穿林打叶声》'
  insight: string,           // 给此刻的你（东坡哲思当代释义）
  microAction: string,       // 今天的一件小事（日常低门槛行动）
  topTraits: string[],       // 核心心境关键词
  timePlace: string          // 时空标签，如 '元丰三年至七年 · 湖北黄州'
}
```

### 3.2 跨场景同源复用规范
1. **Result 结果页**：直接解构 `DongpoAnswer` 渲染 L1 站名与 L2 诗句、哲思、小事；
2. **人生站点卡 (`station_result`)**：Canvas 绘制直接读取 `DongpoAnswer` 数据，确保卡片视觉与页面展示 100% 词句一致；
3. **深入探索上下文**：进入 Station 页面时携带来源标识，站点顶部呈现直达引导文案；
4. **绝对禁止**：禁止不同页面各自分别随机拼接互相冲突的诗句与解释文案。

## 四、全站信息层级：L1 / L2 / L3 / L4

全站各页面统一遵循四级信息层级治理原则，杜绝页面内部争抢焦点：

| 层级 | 级别名称 | 核心定义与要求 | 界面元素与示例 |
|---|---|---|---|
| **L1** | **核心结论与主任务** | 当前页面唯一的首要问题、结论或唯一核心主动作。每屏最多且必须有 1 个 L1。 | “你的人生，正走到苏轼的哪一站？”、“我的东坡答案 / 黄州｜重生” |
| **L2** | **启发与关键动作** | 直接支持 L1 的诗句、当代解释、微行动及主要转化动作。 | 核心诗句引用、给此刻的你、今天的一件小事、主 CTA 按钮 |
| **L3** | **主动深入探索** | 用户主动点击展开或决定深入探索的次级内容，不可在首屏喧宾夺主。 | 站点历史现场长卷、生活实录、诗词星群、折叠详情 |
| **L4** | **资料、出处与注释** | 辅助说明性信息，视觉极度弱化收敛，不干扰主流程阅读。 | 年代、地点出处标注、免责声明、版权与印记 |

## 五、关键页面职责定位

### 5.1 首页 (Home) —— 收益前置，极简驱动
- **第一屏唯一主问题**：“你的人生，正走到苏轼的哪一站？”
- **副说明**：“七次宇宙选择，找到此刻最接近你的东坡人生。”
- **唯一主 CTA**：“开始我的东坡人生实验”；
- **三项轻量用户收益提示**：
  - 测一测：找到我的人生站点
  - 读一句：得到苏轼给此刻的回答
  - 带走它：生成我的东坡人生卡
- **次级探索入口**：“人生星河”与“今日东坡”放置于次级区域，不与主 CTA 争抢同级视觉权重。

### 5.2 东坡人生实验 (Quiz) —— 认知答案的过程
- 保留 7 幕星体碰撞与心境吸附交互；
- 用户自始至终明确认知：“我正在进行 7 次宇宙选择，以拿到我的东坡答案”；
- 完成最后一幕直达“我的东坡答案”，杜绝传统冷冰冰的分数问卷感。

### 5.3 实验结果页 (Result) —— 我的东坡答案
- **页面职责**：告诉用户“我现在在哪一站，以及我今天能带走什么”；
- **L1 结构**：我的东坡答案 / 站点名称｜人生主题；
- **L2 结构**：核心名句 + 给此刻的你 + 今天的一件小事；
- **双明确操作**：
  - 主动作：生成我的东坡人生卡 (Primary)
  - 次动作：进入XX小宇宙深度漫游 (Secondary)
- **彻底剥离**：剥离长篇历史百科与多层标签，不与 Station 页面同质化。

### 5.4 人生星河 (Universe) —— 苏轼完整人生弧线总览
- 回答：“苏轼的一生，到底经历了怎样的起伏？”
- **九站人生弧线化定义**：
  1. `眉山｜出发`（少年才气，走出蜀地）
  2. `京师｜被看见`（名动京师，锋芒初露）
  3. `密州｜豪情`（把酒问月，西北望射天狼）
  4. `乌台｜坠落`（一生最深低谷，生死一线）
  5. `黄州｜重生`（赤壁怀古，东坡定名，人生转折之根）
  6. `杭州｜把日子过好`（疏浚西湖，筑苏堤，爱具体的生活）
  7. `惠州｜随遇而安`（日啖荔枝，不辞长作岭南人）
  8. `儋州｜极境从容`（九死南荒，问汝平生功业）
  9. `常州｜归途`（行过天涯，泊岸归乡，生命落幕）
- **节点轻量预览抽屉 (Quick Sheet)**：大图 + 诗句 + 一句话生活现场 + 唯一次动作“进入XX小宇宙深度漫游”。

### 5.5 今日东坡 (Daily) —— 每天给我一句东坡
- **唯一职责**：每天给我一句东坡；
- **页面主体**：大幅原生场景图 + 一句诗 + 今天可以这样理解 + 今天只做一件小事 + “生成今日诗签”主 CTA；
- **历史背景下沉**：历史现场折叠收纳为 `✦ 读这句诗背后的东坡`；
- **禁止项**：正文页严禁内嵌完整海报，保持页面轻量通透。

### 5.6 站点详情 (Station) —— 主动深入探索
- 明确为用户主动深入后的 L3 内容；
- **顶部来源上下文提示 (Context Banner)**：
  - 若来自实验结果：“✦ 你的东坡答案落在这一站。继续看看苏轼当年是怎样走过来的。”
  - 若来自人生星河漫游：“✦ 你正在探索苏轼人生的「XX时刻」。”
- 严格遵循图文分层与 Text Safe Zone 机制。

## 六、分享卡：三类用户收获资产定义

| 分享卡类别 | 对应类型参数 | 核心心智与文案定位 | 数据与视图来源 |
|---|---|---|---|
| **人生站点卡** | `station_result` | “我现在在哪一站”：展现用户测试所得的人生定位、诗句与微行动。 | `DongpoAnswer` |
| **今日东坡签** | `daily_sign` | “今天我带走哪一句”：提供当天的微行动与东坡诗意慰藉。 | `DailyItem` |
| **人生节点卡** | `station_node` | “我最喜欢苏轼的哪一站”：记录用户在星河漫游中收藏的苏轼人生切片。 | `StationNodeViewModel` |

- **技术门禁**：统一采用 750×1000 逻辑尺寸，由 `CardCanvas` 生成单个稳定 DataURL，预览态、保存态与分享态 100% WYSIWYG。

## 七、视觉与特效退让准则 (Text Safe Zone)

1. **正文安全区真实退让**：
   - 当视口中央存在承载正文的 `[data-text-safe-zone="true"]` 容器时，WebGL 引擎与粒子场景必须主动退让；
   - 粒子透明度从 0.35 阶梯衰减至 0.08 以下，大幅降低粒子视线干扰；
   - 中心大型光晕 (Halo) 透明度衰减至 0.02 且向文本上方退避，禁止刺穿与覆盖阅读区；
2. **兼容性底线**：
   - 严格遵循 ES2017 / Chrome 61 基线规范；
   - 布局严禁使用 Flexbox `gap` 属性，统一使用 `margin` 间距方案；
   - 严格保证纯本地运行，不引入外链 CDN、远程字体、Worker 或 WASM。
