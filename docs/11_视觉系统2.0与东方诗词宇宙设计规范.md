## 一、视觉总原则与美学基调

从传统的“深色文化资料展示页”，全面升维为**“可漫游的东方诗词宇宙”**：

1. **核心美学关键词**：
   - **现代水墨**：浓淡相生、留白呼吸、笔触流淌，而非古风纹样堆砌；
   - **深靛蓝夜幕**：以东方天青、黛青、靛蓝作为宇宙纵深底色；
   - **月光与江面**：水波微荡、月影浮动、清澈澄明；
   - **微星图与星轨**：以文曲星芒隐喻诗人璀璨跌宕的生命轨迹；
   - **克制的人间烟火**：以暖金、杏黄作为节点希望与生活光晕。
2. **禁止的设计风格**：
   - 严禁大面积纯黑背景硬配高亮刺眼白字；
   - 严禁后台管理系统/表单式扁平单调卡片；
   - 严禁俗艳宫廷红金大撞色；
   - 严禁过度赛博霓虹感；
   - 严禁无节制磨砂玻璃拟态导致文字失读。

## 二、四层空间深度架构 (Space Layers)

全站界面构建自下而上的四层视觉深度：

```text
Layer 0: 深靛蓝夜幕底色 (Midnight Navy Base: #0a0e17 ~ #07090e)
    ↓
Layer 1: 远山 / 云雾 / 江天 (Mountain & Mist Silhouette, 墨韵流动)
    ↓
Layer 2: 月光 / 微星轨 / 江水反光 (Moonlight Ripples & Starlight)
    ↓
Layer 3: 前景文学内容 / 交互卡片 / 核心操作 (Foreground Content & UI)
```

**WebGL 解耦原则**：
- Layer 1/2 支持由 Three.js 水墨粒子与流动星轨实现；
- 在 WebGL 未加载或低端设备回退时，纯 CSS 多层径向渐变与水墨光晕无缝承接；
- Layer 3 的 DOM 结构绝对独立，保证无论图形层如何降级，文字与交互操作始终 100% 可用。

## 四、四大语义卡片体系 (Semantic Cards)

1. **人生站点卡 (`.ink-card-station`)**：
   - 特征：左侧带有意象微光标尺，上方标注年代与历史时空芯片，背景沉淀深靛蓝与微山影渐变；
2. **诗词名作卡 (`.ink-card-poem`)**：
   - 特征：上下东方水墨边饰，名句采用大字号（20~22px）书法排版，两端适度文学留白，带印章标头；
3. **今日东坡签 (`.ink-card-daily`)**：
   - 特征：信笺质感，细红或暖金朱砂印章，日期大字排版，行动建议作为独立淡墨小票呈现；
4. **叙事解读卡 (`.ink-card-narrative`)**：
   - 特征：柔和半透底色，左侧轻量水墨引导线，层次分明，排版疏朗。

## 五、移动端与无障碍规范

- 严格遵循 Chrome 61 兼容（零裸漏 `gap:`，配置兄弟选择器 fallback；`aspect-ratio` 兜底）；
- 双安全区完美对齐（`var(--safe-area-inset-*, env(safe-area-inset-*, 0px))`）；
- 支持 `@media (prefers-reduced-motion: reduce)` 系统减弱动效降级；
- 320px 窄屏防截断保护，单行诗句长文本自适应折行与标点避头尾。
