# 任务15 全站视觉系统2.0与东方诗词宇宙体验重构 计划

> 项目：苏轼宇宙小红书小工具  
> 阶段：Visual 2.0 升级  
> 任务目标：在保留已有业务逻辑、数据结构与 Skill 1.6.0 离线单页规范的前提下，全面升级视觉语言，从“普通深色文化 H5”重构为“可漫游的东方诗词宇宙”。

---

## 一、实施目标与改造范围

1. **产出设计规范 (`docs/11_视觉系统2.0与东方诗词宇宙设计规范.md`)**：
   - 确立“现代水墨 × 深靛蓝 × 月色 × 江水 × 微星图 × 人间烟火”的东方宇宙美学；
   - 规定四层空间深度（夜幕底色、远山云雾、月光江影、前景内容）；
   - 定义四类语义卡片（人生站点卡、诗词卡、今日东坡签、结果解读卡）；
   - 规定 9 大人生站点色彩意象与情绪转折（乌台至暗墨雨 → 黄州江月由暗转明）。
2. **重构 Design Tokens (`css/tokens.css`)**：
   - 新增多层空间深度变量、9 大人生站点色彩阶段变量（墨青/灰蓝/霁蓝/黛紫/暖金）；
   - 扩展卡片质感变量（渐变底色、内发光、微边框、东方柔和阴影）。
3. **重构 App Shell 与背景容器 (`css/base.css`, `index.html`)**：
   - 在 `index.html` 的 App Shell 中引入 `#universe-bg-canvas` 容器（为任务 15.1 的 Three.js 预留画布挂载点）；
   - 实现多层现代 CSS 水墨流光、微星点与呼吸光晕作为稳固的无 WebGL 降级层。
4. **重构核心视图与交互排版 (`css/views.css`, `css/components.css`, `js/views.js`)**：
   - **首页**：东方山水江月留白，文人气息 Hero 文案与强 CTA，今日东坡精选预览；
   - **测试页**：月相/江程步进器，人生情境沉浸卡，触控水波反馈；
   - **结果页**：“东坡时刻”记忆点，站点情绪色温浸润，七层叙事阶梯；
   - **人生宇宙**：生命长河/星轨流动流线，九大站点沿江展开；
   - **作品详情**：文学留白，名句书法卡，现代启发；
   - **今日东坡**：水墨日历信笺，一诗一言一小行动；
   - **分享卡预览**：画轴装裱感外框与精致操作区。
5. **自动化测试、移动端截图与官方双引擎审计**：
   - 启动本地服务，使用移动端视口（390×844）截取整套视图高保真截图；
   - 运行全量 12 套自动化测试套件；
   - 运行 `scripts/build_and_audit.py`，官方 Python & Node.js 双引擎双对象全绿审计；
   - 产出成果说明、更新开发日记并提交 Git。
