# 任务15.6.8.1：结果语义一致性、今日东坡排版校正、Canvas字号重构与全站粒子降噪实施计划

## 一、任务背景与核心目标

根据任务定义文件 `tasks/任务15.6.8.1_结果语义一致性_今日东坡排版校正_Canvas字号重构与全站粒子降噪01.md`，本次任务旨在关闭当前版本最后一批具有明显用户感知的语义错误与视觉噪音，达成“文字清楚、图片有张力、海报像海报、粒子只做氛围、不再抢阅读”的最终目标。

核心实施要点：
1. **P0 语义一致性**：彻底解除旧 `mood_id` 对代表诗句和主人生解释的决定权。以 `station_id` + station profile 为主导，确保 9 站结果页与分享卡绝不发生跨站错配。
2. **P1-A 今日东坡排版**：消除旧 `.daily-poetry-slip` 的 `min-height: 380px` 与 `space-between` 导致的纵向拉散，实现诗句、出处、日期紧凑连续排列，并在 390px 视口下保证短诗单行展示。
3. **P1-B & P1-C Canvas 字号与信息预算**：750×1000 Canvas 内部重构字号标尺（站名 42~52px，诗句 36~46px，正文 26~30px，辅助信息 22~26px），三类卡片彻底做信息减法，基于 `cursorY` 动态递推布局，消除上挤下空。
4. **P1-D 全站粒子降噪**：全站 WebGL 粒子尺寸缩小至 0.04~0.065，透明度降至 0.25~0.45，采用离线动态圆形柔光纹理消除硬方块感，正文区域主动弱化。
5. **P2 预览页空间优化**：保持 3:4 真实海报居中与同一 DataURL，四周增加柔化环境延展背衬，优化高屏手机观感。
6. **自动化测试与验收**：新建 `scripts/test_result_semantics_layout_particles_15_6_8_1.py`，全量回归现有测试，Playwright 真实浏览器截图归档，构建最终 ZIP 并完成 Git commit + push。
