# 任务15.6.7 全站图文分层、图片原生张力与文字安全区统一整改计划

## 1. 任务背景与核心目标

在任务 15.6.6.1 解决 CSSOM 兼容性与 3D/Fallback 稳定性的基础上，真机与无头浏览器运行中仍暴露了关键视觉体验痛点：
1. **图文叠层滥用与严重撞色**：站点详情页 Hero 和 Scene 2 绝唱名句将标题、年代、标签、题记或正文诗句直接压在场景图上，当遇到亮色水汽/天空或复杂深浅斑驳时，文字失读严重；
2. **大图原生张力被封印**：为顾及压图文字，图片往往被迫施加暗黑蒙版或全图模糊，水墨场景的东方意境与原生张力被严重削弱；
3. **视觉层次倒错**：图本应是空间场景或视觉主角，正文应在稳定安全的版式区供人细读。

**任务 15.6.7 的核心目标**：全面确立“图文分层、原生张力、文字安全区、镜头式长卷”四大铁律，把图片还给眼睛，把文字还给阅读。

---

## 2. 实施方案与技术要点

### 2.1 站点详情页 Hero：双段式垂直重排
- **镜头0 · 原生场景图**：高度约 240px~280px（首屏约45%~55%），保持 100% 原色直出，废除全图暗色遮罩与 blur，仅在底部留存 ≤ 10% 自然羽化过渡层；
- **镜头0.5 · 独立信息区**：彻底移至场景大图下方，背景使用页面稳定的深靛底色（`#0d1526` / 自然渐变），承载站序徽标、站名大标题、年代地名、关键词标签群、站点题记；
- **兼容性保障**：保留原有 `.station-hero-card`、`.station-hero-cover-box`（height: 280px）、`.station-hero-cover-img`（opacity: 0.90 兼容原有测试正则）、`.station-safe-zone-content` 等关键类名，从样式上将文字内容从绝对定位叠层改为垂直流式布局。

### 2.2 镜头B：Scene 2 代表名句长卷重构
- **意境大图在上**：保留 `.station-verse-scene-stage` 与 `.station-verse-scene-img`（高度约 200px~240px），原色山水直出，纯粹留白观景；
- **名句独立在下**：`.station-verse-scene-content` 垂直排列在大图下方独立深色文本区，不再浮动遮挡山水画面中心；
- **字体与字色阶梯**：大字号楷体/宋体（22px~24px）暖白（`#fbf8ee`）展示名句，淡金（`#d9b978`）居中/居右展示出处，辅以淡金色轻微下细线。

### 2.3 今日东坡页面整改
- **重构图文结构**：大图在上原色完整直出；主诗句与出处下移至独立文本区；
- **下半区丰满平衡**：第一幕真实生活现场、第二幕放到今天、第三幕今天只做一件小事依次舒展排布，解决“上半图极其拥挤、下半深蓝大片空白”的失衡；
- **兼容性保障**：保持原有 3:4 诗签容器与 Canvas 同源生成链路，确保分享卡 DataURL 稳定。

### 2.4 Text Safe Zone（文字安全区）与文字色收口
- **安全区防护**：为正文容器追加 `data-text-safe-zone="true"` 及 CSS 保护层，提供微弱背景遮蔽，杜绝背景动态粒子/WebGL高光直接刺穿字形；
- **文字色收敛为三层**：
  1. 主层：暖白/米白（`#f5eedc` / `#fbf8ee` / `#f0eee9`），高对比、阅读舒适；
  2. 强调层：淡金/古金（`#d9b978` / `#e5c17d` / `#ffe082`），用于核心名句、徽标；
  3. 辅助层：青灰/浅灰（`#8ca0b8` / `#a0b2c6` / `#94a3b8`），用于年代、出处副标；
- **对比度达标**：常规正文严格达到 WCAG AA（≥ 4.5:1）。

### 2.5 冻结范围保护
- 首页三大星体入口、人生星河九站主轴、节点 viewport 弹层逻辑；
- 东坡人生实验 28 题题库 / 7 幕随机 / autoTravel；
- 3D PoetryPlanet 单层架构与 2.5D Fallback；
- Canvas WYSIWYG 同源链路；
- Router / historyStack、Cosmic Dock。
