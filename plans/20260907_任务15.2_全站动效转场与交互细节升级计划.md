# 任务15.2 全站动效、转场与交互细节升级 计划

> 项目：苏轼宇宙小红书小工具  
> 阶段：Visual 2.0 Motion Polish  
> 前置任务：任务15、任务15.1  
> 核心目标：在不影响可读性和低端真机性能的前提下，将全站从“静态精美”提升为“有呼吸、有节奏、有空间连续性”的完整作品。

---

## 一、实施目标与打磨范围

1. **页面级连续转场 (`css/views.css`, `js/views.js`, `js/router.js`)**：
   - 全局视图平滑入场（由水墨微升 + 平滑透明渐入，时长 280~320ms，纯 `transform` 与 `opacity`）；
   - 首页 → 测试：Hero 标题轻微上升浮隐，题目卡自江面水雾中升起；
   - 测试题步进切换：从硬替换升级为 220ms 平滑横向/纵向淡入（`.quiz-step-enter`），进度江程/月相平滑步进；
   - 测试 → 结果揭晓：协调 WebGL 粒子向心汇聚，1.0 秒内七层卡片如卷轴般优雅递进展开；
   - 快速返回（Back）：动作明确直接，可随时中断，绝不卡死等待动画。
2. **测试微交互与触控安全 (`js/views.js`, `css/views.css`)**：
   - 确保每个选项触控目标高度 >= 44px（符合移动端无障碍人机工效）；
   - 选项按压水墨水波即时高亮反馈，引入防连击防抖锁（防止用户狂点跳过两道题）；
   - 返回上一题保留已有选择状态；
   - 最后一题提交自然过渡，避免瞬间空白跳动。
3. **人生宇宙长河滚动与节点空间感 (`js/views.js`, `css/views.css`)**：
   - 宇宙生命线节点视口接近激活（`.is-active` / `.is-focused`）；
   - 乌台至暗墨雨到黄州破晓赤金的转折加深视觉感知；
   - 快速惯性滚动时自动降解非必要复杂阴影与动画，保持 60fps 丝滑。
4. **诗词阅读与今日东坡仪式感 (`js/views.js`, `css/views.css`)**：
   - 诗词页克制宁静：名句书法卡月光微聚，现代生活解法分层入场，禁止刺眼打字机或悬浮抖动；
   - 今日东坡：朱砂印泥签卡入场具有轻微“盖印”仪式感（`.stamp-press-in`），一诗一言一事递进展示；
   - 分享卡预览：Canvas 绘制中水墨加载动效，生成完毕后画轴平滑装裱展开，操作按钮提供清晰反馈。
5. **Reduced Motion 与低端降级联动 (`css/base.css`, `css/views.css`, `js/effects/quality-manager.js`)**：
   - 监听 `prefers-reduced-motion: reduce`，所有动画时长自动降为 `0.01ms`；
   - 当 QualityManager 降为 `low` 或 `fallback` 时，在 DOM 根节点同步标记 `.quality-low`，禁用滤镜模糊与复杂阴影。
6. **自动化测试、移动端录屏/连续截图与官方审计**：
   - 编写任务 15.2 专属测试套件 `scripts/test_motion_transition_flow.py`；
   - 使用 Chrome DevTools MCP 在 390×844 视口下截取转场与微交互连续成果截图；
   - 运行全量 13 套自动化测试套件与官方 Skill 1.6.0 双引擎审计；
   - 产出成果说明、更新开发日记并提交 Git。
