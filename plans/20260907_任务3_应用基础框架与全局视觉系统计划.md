## 一、核心理解与执行目标

任务3的核心任务是**在离线 H5/CSP Safe/Chrome 61 严格约束下，交付高品质、统一视觉、高内聚的 App Shell 与逻辑视图路由框架**，达成 Milestone A。

### 核心执行原则
1. **纯离线经典脚本**：全采用 Classic Script + `window.SuShiUniverse` 命名空间管理，严禁 ES Module、严禁任何内联 JS 与行内事件；
2. **Design Tokens 集中化**：在 `css/tokens.css` 中严格定义色彩、字阶、间距（4pt/8pt体系）、圆角、阴影、安全区（双兼容 `var(..., env(...))`）；
3. **现代水墨东方美学视觉层**：深靛蓝夜色（`#0E1830`）+ 月白（`#F4F0E6`）+ 江水青（`#6FAFC2`）+ 苍竹玉（`#82B6A2`）+ 暖灯火（`#D9B978`），低饱和、通透松弛；
4. **轻量视图路由器**：实现 `SuShiUniverse.Router`，支持 8 个核心逻辑视图（`home`, `quiz`, `result`, `universe`, `station`, `work`, `daily`, `share-card`）的无缝进出与历史栈管理；
5. **Chrome 61 基线兼容**：Flex 关键布局不单独依赖 `gap`（采用 margin 基线兜底），杜绝 `aspect-ratio`、`clamp()` 等不兼容属性；
6. **自动化 E2E 验证与截图**：通过自动化浏览器工具对各视图与组件状态进行测试，自动保存截图至 `Walkthroughes/screenshots/20260907_任务3_应用基础框架与全局视觉系统/`；
7. **官方 Skill 1.6.0 双审计**：经 Python 与 Node.js 官方脚本审计产物目录及 ZIP 包，确保 100% 达标。

## 三、实施步骤与验证闭环

1. **Step 1: 建立视觉设计系统 Tokens (`css/tokens.css`)**
   - 贯彻 `docs/04` 颜色、字阶、留白系统。
2. **Step 2: 建立基础样式与兼容层 (`css/base.css`)**
   - 安全区双兼容、小屏无横向滚动、Chrome 61 弹性伸缩与间距回退。
3. **Step 3: 建立通用 UI 模块样式与辅助工具 (`css/components.css` & `js/ui.js`)**
   - PageShell, SectionHeader, PrimaryButton, SecondaryButton, InkCard, QuoteBlock, Tag, ProgressBar, BackButton, Loading/Empty/ErrorState。
4. **Step 4: 实现轻量逻辑视图路由器 (`js/router.js`)**
   - 8 个视图的导航管理、参数传递、历史回退。
5. **Step 5: 实现各视图基础原型与壳层联动 (`js/views.js`)**
   - 在各视图内展示规范 UI 模块，验证全流程通畅。
6. **Step 6: 组装 `index.html` 与更新 `js/app.js`**
   - 严格审查无内联脚本、无行内事件。
7. **Step 7: 运行数据校验与官方 Skill 1.6.0 双审计**
   - 执行 `python scripts/build_and_audit.py`，确保目录与 ZIP 双 PASS。
8. **Step 8: 自动化 E2E 验收与规范截图保存**
   - 启动本地服务，使用 DevTools 自动化模拟移动端测试并捕获关键视图截图至指定目录。
9. **Step 9: 归档成果与提交**
   - 输出成果说明文档、更新开发日记并提交 Git。
