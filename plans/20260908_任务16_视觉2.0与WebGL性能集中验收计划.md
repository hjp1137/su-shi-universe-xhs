## 一、任务核心理解与目标

本任务是一次对全站“视觉系统2.0 + Three.js/WebGL 水墨宇宙特效 + 动效与交互 + 移动端5大视口安全区 + 包体合规性 + 产品主链路”的**全面集中验收**。核心目标是杜绝“视觉好看了但性能、兼容、真机操作反而退化”，给出客观、可复现、带证据的验收结论。

必须严肃回答五大核心问题：
1. 页面是否真的比 V1 有质变？
2. Three.js 是否克制并合理使用，无滥用？
3. WebGL 失败/低性能时产品是否仍然100%完整可用？
4. 升级后是否严格符合 Skill 1.6.0 规范？
5. 真机与移动端环境下是否达到稳定比赛交付标准？

---

## 二、验收执行维度与要点

### 1. 视觉集中验收（Before / After 对比）
- 对比 7 大核心页面（首页、测试页、黄州结果页、人生宇宙、作品详情、今日东坡、分享卡全屏舞台）；
- 核验 9 项视觉标准：东方现代水墨识别度、双视觉高潮、生命长河感、诗词阅读舒适度、非西式星空、正文与 CTA 零遮挡。

### 2. WebGL 架构 13 项硬核审查
- 依赖完全本地化（Three.js r128 锁定，零外部 CDN，零 WASM，零 Worker，零运行时 ESM）；
- 增强层架构（DOM 独立，WebGL canvas 为 `pointer-events: none`）；
- 异常容灾（初始化失败 Fallback、WebGlContextLost 自动降级纯静态水墨、场景切换完整 destroy 释放内存与几何体、后台 visibilitychange 暂停 RAF 避免耗电、像素预算严格控制 ≤200 万像素并限制 DPR ≤ 2）。

### 3. 性能档位验收（Medium / Low / Fallback / High）
- 验证 QualityManager 四档策略；
- 验证在各档位下主流程 100% 完整可用，Native Bridge 无缝协同。

### 4. 移动端尺寸与安全区集中验收
- 覆盖 5 档典型宽度：320px、375px、390px、430px、480px；
- 验证刘海/灵动岛与底部 Home Indicator 避让、标题不顶边、长诗不截断、站点节点不出屏、分享卡不溢出、零意外横向滚动。

### 5. 动效与无障碍集中验收
- 转场平滑统一、揭晓时间克制、支持 `prefers-reduced-motion`、防连击与防重复推进、无残留弹窗/遮罩、长滚动自动收敛特效、背景克制不抢眼。

### 6. 包体与资源预算集中验收
- 统计最终 ZIP 大小（目标 <= 2 MiB 优秀，当前约 2.48 MiB 需对前三大资源合理解释，且严格 <= 10 MiB 门禁）；
- 统计 Three.js 运行时体积、新增素材体积、前五大静态资源；
- 零高风险超大内联 Base64。

### 7. 官方 Skill 1.6.0 重新审计
- 产物目录与 ZIP 双对象双引擎审计；
- 静态 API 与禁用特性扫描；
- 最终产物校验脚本 `verify_final_package.py`。

### 8. 全链路产品回归与抽查
- 完整主路径：首页 → 微游戏 → 结果 → 站点 → 人生宇宙 → 作品 → 今日东坡 → 分享卡 → 保存/发布；
- 抽查 8 大心境、9 大站点、21 篇作品可达性、今日东坡同日稳定性。
