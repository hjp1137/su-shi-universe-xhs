# 任务15.5.1 Canvas站点卡运行时修复与分享卡动态渲染门禁实施计划

## 1. 任务背景与核心目标

在任务 15.5 验收复核中，发现 `js/card_canvas.js` 内部 `renderStationResultCard` 函数签名未声明 `assets` 形参：
```javascript
function renderStationResultCard(ctx, vm, width, height) // 缺失 assets
```
但在函数体内部却尝试访问局部变量 `assets`：
```javascript
if (assets && assets.scene) {
  drawImageCover(ctx, assets.scene, 0, 0, width, 390, 150);
}
```
并且在 `CardCanvas.renderCard` 调用处实际传递了 5 个参数：
```javascript
renderStationResultCard(ctx, viewModel, CANVAS_WIDTH, CANVAS_HEIGHT, assets);
```
由于 JS 忽略未声明的多余形参，导致 `renderStationResultCard` 内部引用 `assets` 存在 `ReferenceError: assets is not defined` 运行时缺陷，阻断结果页生成人生站点卡的主链。

同时，原任务 15.5 专属测试主要基于静态字符串模式匹配，未能拦截该真实运行期缺陷。

本任务目标：
1. 修复 `renderStationResultCard` 函数签名并全面排查 `card_canvas.js` 作用域传参；
2. 编写真实 Canvas 动态渲染门禁测试脚本 `scripts/test_card_canvas_runtime_15_5_1.py`；
3. 更新静态专属测试 `scripts/test_navigation_share_universe_15_5.py`；
4. 真实浏览器环境渲染并捕获 4 张卡片（站点卡、每日签、节点卡、Fallback卡）留证；
5. 全量回归测试通过、官方双引擎双对象审计通过、构建最终规范包。

---

## 2. 实施步骤

### 步骤一：修复代码与作用域排查
1. 修改 `js/card_canvas.js`：
   - 将 `function renderStationResultCard(ctx, vm, width, height)` 修正为 `function renderStationResultCard(ctx, vm, width, height, assets)`；
   - 排查 `loadLocalImage`、`loadLocalImages`、`drawImageCover`、`renderDailySignCard`、`renderStationNodeCard`、`CardCanvas.renderCard`，确保全部形参与闭包变量显式传递，不依赖全局变量或偶然属性。
2. 确保在图片加载失败或离线场景下，继续平滑回退到 `drawBackground` 程序化水墨渐变背景，不白屏、不报错。

### 步骤二：静态专属测试补强
修改 `scripts/test_navigation_share_universe_15_5.py`：
- 增加对 `renderStationResultCard` 函数签名必须显式包含 `assets` 形参的正则检查；
- 检查三类卡片渲染函数均显式声明接收 `assets`。

### 步骤三：编写真实执行级动态渲染门禁脚本
新建 `scripts/test_card_canvas_runtime_15_5_1.py`：
1. 启动轻量本地 HTTP 静态服务器；
2. 启动真实无头浏览器（Headless Chrome / Edge）；
3. 真实加载完整运行环境（包含 `js/data.js`、`js/art_assets.js`、`js/card_canvas.js`）；
4. 逐项真实调用 `CardCanvas.renderCard`：
   - ① `station_result`（人生站点卡，黄州）：验证正常返回有效 DataURL，长度远大于空白图，无 ReferenceError/TypeError；
   - ② `daily_sign`（今日东坡签）：验证正常返回有效 DataURL；
   - ③ `station_node`（人生节点卡）：验证正常返回有效 DataURL；
   - ④ 模拟图片加载失败（Fallback）：验证即便所有素材加载失败，也能在 200ms 内优雅回退并返回有效 DataURL，不白屏、不无限等待。
