# 任务1 小红书官方 Skill 接入与工程骨架初始化计划

## 核心理解与目标
严格执行 `tasks/任务1_小红书官方Skill接入与工程骨架初始化01.md`，基于官方 Skill `minitool-zip-builder-1.6.0.skill` 提取小工具的硬性工程约束，不预设普通 Web 方案，确立符合官方要求的工程目录与文件结构，搭建包含核心要素（“苏轼宇宙”、Slogan、基础按钮、本地静态资源、移动端安全区）的最小工程骨架，并执行官方 Skill 校验闭环。

## 执行步骤
1. **获取并解压官方 Skill**：
   - 从 `https://fe-static.xhscdn.com/mini-tool/20260831163932/minitool-zip-builder-1.6.0.skill` 下载官方 Skill。
   - 解析 Skill 包结构，放置在 `.skill/` 以及 `.claude/` 目录下，完整阅读 `SKILL.md` 及附带脚本。
2. **整理官方工程约束摘要**：
   - 提取入口、文件组织、本地静态资源、平台 API、校验命令、打包等硬性要求。
   - 编写并提交 `docs/07_小红书官方Skill工程约束摘要.md`。
3. **初始化最小工程骨架**：
   - 严格根据官方规范要求建立入口文件（如 index.html 等）与源码/静态资源目录。
   - 编写最小页面：包含“苏轼宇宙”、Slogan “遇到烦心事，先去东坡那里坐一会儿。”、基础按钮、本地静态图片资源、viewport 与安全区适配。
4. **执行官方校验闭环**：
   - 运行官方 Skill 提供的校验脚本，检查当前工程。
   - 若有错误，定位根因并修复，重新执行校验，确保零阻塞性错误。
5. **归档交付与代码提交**：
   - 编写成果说明文档 `Walkthroughes/20260907_任务1_小红书官方Skill接入与工程骨架初始化成果说明.md` 及 `tasks/results/20260907_任务1_小红书官方Skill接入与工程骨架初始化01成果说明.md`。
   - 追加更新 `开发日记.md`。
   - 提交 Git Commit。
