## 一、核心理解与执行要点

1. **P0-A 海报舞台真实 3:4 比例最大化（告别高容器缩放假全屏）**
   - **根因**：先前海报容器强撑至 714px 高度，但在 390 宽屏幕下 3:4 的真实 Canvas 图片受 `object-fit: contain` 限制仅能展示为约 367×489，导致容器内上下留出 225px 巨大空缺。
   - **执行要点**：海报舞台尺寸严格服从海报自身 3:4 比例（`posterWidth = min(availableWidth, availableHeight * 3 / 4); posterHeight = posterWidth * 4 / 3`）。海报图片与容器 100% 贴合，`img.getBoundingClientRect()` 与外框完全一致，宽高比严格等于 `0.75 ± 0.01`，上下空白总量 ≤ 0px，彻底消除假全屏留白；保持 Canvas DataURL = `img.src` = `saveImageToPhotosAlbum` = `postNote` 同源 WYSIWYG。

2. **P0-B 站点真正无块化（连续镜头人生长卷）**
   - **根因**：虽然去除边框，但依然保留了“卷标题 badge + 深色文字块（`rgba(12, 20, 36, 0.65)` + `blur(4px)`）+ 卷标题 + 图片块”的无边框列表结构。
   - **执行要点**：彻底废除章节大 badge 与正文大面积深色背景/blur 磨砂板；构建由细金星轨贯穿的“Hero全景 → 金线引路史实切片 → 代表名句第二意境镜头（原色通透直出，文字融入留白） → 生活实录步伐 → 3D诗词星群无界嵌入 → 现代共鸣轻量收束”真实连续长卷；针对眉山、黄州、杭州、惠州、儋州实现差异化构图与明暗文字自适应（WCAG AA ≥ 4.5:1）。

3. **P0-C 3D诗词星群彻底单层化（WebGL模式只允许一套PoetryPlanet）**
   - **根因**：`UI.createConstellationGroup` 在创建 3D 舞台的同时，无论 WebGL 是否运行，都固执地在同一个 DOM 容器中渲染了 2D SVG 轨道、旧 coreNode、旧 6 颗带图 star-node 和气泡，导致 3D 旋转层与 2D 固定层物理叠加；且 Fallback 模式下又堆出了 Chip。
   - **执行要点**：架构单层化隔离。WebGL 模式下彻底禁止并移除任何 2D star-node、SVG 轨道、旧 coreNode 与旧气泡，PoetryPlanet 作为唯一的视觉、运动、命中与标签主体；星球本体采用东方水墨缩略纹理与东方五色调，拖拽时 100% 同轴刚体旋转位移；点击星球最短路径转到眼前并放大 1.8~2.2 倍，仅展现贴着星球的极轻微附着式文字（宽度 ≤ 40% 舞台，高度 ≤ 90px，名句 1~2 行），绝无大矩形框；Fallback 模式提供单层纯净 2.5D 星宿环，杜绝任何白底 Chip 与叠层。
