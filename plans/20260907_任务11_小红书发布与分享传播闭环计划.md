# 任务11：小红书发布与分享传播闭环 0.1 实施计划

## 1. 任务背景与核心目标

- **任务编号**：任务11 (`tasks/任务11_小红书发布与分享传播闭环01.md`)
- **阶段定位**：Competition Polish（P0 核心资产 / 闭环传播链）
- **核心目标**：基于官方 Skill 1.6.0 规范，完善 `SuShiUniverse.Bridge`（`XHSBridge`）统一适配层，打通：
  > **测试/浏览 → 分享卡 → 写临时文件 (writeTempFile) → 保存相册 (saveImageToPhotosAlbum) 或调起发布 (postNote) → 成功/取消/失败反馈 → 恢复产品状态。**
- **严禁事项**：严禁未经确认自动发帖；严禁使用 `<a download>`；严禁网络上传/fetch/外链；用户取消属于正常业务分支，不当作错误抛出。

## 2. 技术设计与关键改造点

### 2.1 XHSBridge 统一适配层升级 (`js/bridge.js`)
1. **命名空间与别名**：同时暴露 `SuShiUniverse.Bridge` 与 `SuShiUniverse.XHSBridge`；
2. **API 规范严格遵从**（参考 `references/jsbridge-api.md`）：
   - `isAvailable()`：判断 `window.xhs && window.xhs.miniTool`；
   - `writeTempFile(dataUri)`：
     - 校验 `dataUri` 是否以 `data:<mime>;base64,` 开头；
     - 真机环境调用 `window.xhs.miniTool.writeTempFile`；
     - 模拟环境生成 `mock://temp/card_${Date.now()}.png` 并成功 resolve；
   - `saveImage(filePathOrDataUri)`：
     - 若传入 data URI，自动先调用 `writeTempFile` 换取 `filePath`，再调用 `saveImageToPhotosAlbum({ filePath })`；
     - 识别真机权限拒绝（提示“请在设置中开启相册访问权限”）；
     - 识别用户取消（`cancel` 关键字），归一化为 `{ canceled: true }`；
     - 模拟环境温和 Toast 提示并成功 resolve；
   - `postNote(options)`：
     - 校验 `mediaInfo` 必填；
     - 必须由用户主动点击触发；
     - 支持 `title`（≤20字）、`content`（≤1000字）、`pageType: "photo_publish"`、`mediaInfo: { image_resources: [{ url: filePath }] }`、`tags`；
     - 识别用户取消，返回 `{ canceled: true }`；
     - 模拟环境温和 Toast 提示并成功 resolve；
   - `openRedPage(options)`：通用原生页面跳转封装；
3. **错误码与用户取消归一化**：
   - 统一返回包含 `success: boolean`, `canceled: boolean`, `errMsg: string` 的标准结果结构；
4. **防并发保护**：
   - 内部增加调用锁 `isProcessing`，当保存或发布进行中时忽略重复点击，防止 Native 容器被频繁并发调用崩溃。

### 2.2 传播闭环主链升级 (`js/views.js` & `css/views.css`)
1. **分享卡视图操作区双主键设计**：
   - 主按钮 1：`一键发布到小红书`（高贵金质主按钮，带有醒目行动感）；
   - 主按钮 2：`保存卡片至相册`（深靛蓝副主按钮）；
   - 辅助按钮：`漫游苏轼人生宇宙`、`测测我的人生状态`、`返回首页`；
2. **克制自然的预填发布文案**：
   - 人生站点卡：
     - 标题：`我的苏轼人生站点`
     - 正文：`原来我最近在苏轼的“${station_name}”。遇到不可控的风雨，不如在心里给生活留十分钟的从容与徐行。`
     - 标签：`#苏轼宇宙 #中国诗词宇宙 #东坡人生`
   - 今日东坡签：
     - 标题：`今日东坡诗签`
     - 正文：`今天抽到了东坡的名句：“${quote_text}”。${dongpo_view} 今天做一件小事：${today_action}`
     - 标签：`#今日东坡 #诗词日历 #生活哲学`
   - 人生节点卡：
     - 标题：`苏轼人生行迹`
     - 正文：`行至${station_name}，${summary_fact} 依然可以在城头看一轮明月。`
     - 标签：`#苏轼生平 #人生站点 #东坡行迹`
3. **状态反馈与防卡死保护**：
   - 点击发布或保存时，按钮进入 Loading 态并置灰；
   - 无论成功、取消、失败，最终 `finally` 必定恢复按钮可交互状态，杜绝卡死；
   - 成功提示：“已成功调起发布 / 已保存至相册”；
   - 取消提示：“已取消操作”。
