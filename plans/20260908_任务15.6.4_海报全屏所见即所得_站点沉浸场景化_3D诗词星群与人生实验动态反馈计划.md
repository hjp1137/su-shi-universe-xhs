## 一、背景与目标

针对前序复验暴露的“卡片仍像缩放预览图、站点仍是纵向模块列表、大面积遮罩压暗好图、星群2D且作品少、人生实验点击无飞行反馈”四大视觉与交互深层问题，执行 P0 级结构性跃迁整改：

1. **P0-A 卡片系统重构为全屏 WYSIWYG 海报**：390px 视口下海报占 98%~100% 宽度，消除二次装裱边框，三类卡构图彻底拉开差异，保持 Canvas DataURL = 预览 = 导出完全一致；
2. **P0-B 站点沉浸式场景镜头叙事与可读性安全区**：Scene 0 ~ Scene 6 场景镜头推进，彻底废除整图遮罩，图片原色直出，建立 `textSafeZone` 安全排字区与 tone 色彩自适应；
3. **P0-C 9站每站≥10真实作品与 3D 诗词星群**：扩充至 ≥90 篇真实史料作品，补全真实关系字段；基于本地 Three.js 构建可手势拖拽旋转、惯性衰减的 3D 星群；点击最短路径聚焦，星旁轻量展示，无大弹框；支持 2.5D CSS Fallback；
4. **P0-D 人生实验题库扩充至 28 题与心识星 autoTravel 飞行碰撞**：覆盖 10 大维度，每题带 interactionType 与语义 hint；无论拖拽还是点击目标星均触发 450~700ms 动态飞行，接触瞬间触发 collision/merge/split/gravity 等专属宇宙反馈；
5. **自动化测试、截图与 Git 交付**：3 套专属测试 + 22+ 套回归测试 + ≥20 张真实截图 + Skill 1.6.0 双引擎审计 (≤10MiB) + Git commit & `git push origin main`。
