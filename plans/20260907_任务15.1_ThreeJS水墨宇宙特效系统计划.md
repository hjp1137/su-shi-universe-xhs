# 任务15.1 Three.js水墨宇宙特效系统 计划

> 项目：苏轼宇宙小红书小工具  
> 阶段：Visual 2.0 / WebGL Enhancement  
> 前置任务：任务15  
> 核心原则：Three.js 只负责“宇宙感、空间感、氛围与镜头感”，DOM 负责内容与操作；任何 WebGL 失败都不得影响核心功能，零业务耦合。

---

## 一、实施目标与技术选型

1. **Three.js 版本选型与规范锁定**：
   - 选型版本：**Three.js r128 (`0.128.0`)**。
   - 选择理由：
     - WebGL 1 与移动端 WebView 的黄金稳定基线，原生向下兼容 ES2017 / Chrome 61；
     - 具备成熟稳定的 UMD/Classic Script 离线打包产物；
     - 零网络请求、零外部字体/纹理、零 WASM/Worker 依赖；
     - 针对 Skill 静态扫描进行正则冲突规避（处理 terser 压缩产生的 `new function()` 伪特征）；
     - 包体增量可控：压缩后仅增加 ~140 KB，总 ZIP 约 265 KB，远低于 ≤ 2048 KB 的强推荐上限（占比仅约 13%）。
2. **WebGL 架构与四层解耦**：
   - 最底层：静态夜幕底色与远山降级（Level 0）；
   - WebGL 层：`#universe-bg-canvas` 动态透明水墨空间（Level 1）；
   - DOM 内容层：`#app` 语义卡片与交互按钮（Level 2-3）；
   - 建立模块化架构：
     ```text
     js/effects/
     ├── quality-manager.js  # 四档自适应降级管理 (High / Medium / Low / Fallback)
     ├── fallback.js         # 纯 CSS/Canvas2D 优雅降级引擎
     ├── webgl-engine.js     # WebGL 渲染引擎 (生命周期/预算控制/容错)
     ├── hero-scene.js       # 首页东方宇宙 Hero (低亮月体/远山/江面/微星/视差)
     ├── universe-scene.js   # 东坡人生星河 (九大站点情绪参数化流动)
     ├── result-scene.js     # 测试结果揭晓 (短时粒子聚拢/光晕渐显)
     └── index.js            # 统一出口挂载至 SuShiUniverse.Effects
     ```
3. **三大核心特效场景**：
   - **Scene 1 (Hero 东方宇宙)**：月轮、层次远山剪影、江面水光微澜、极稀疏水墨星点（30-60点）、Pointer 视差、低频呼吸缓动；
   - **Scene 2 (东坡人生星河)**：单一场景复用，生命长河星轨沿江流动，九大人生站点专属色温与氛围参数切换（眉山翠青/京师曙蓝/密州苍灰/乌台墨雨/黄州江月破晓/杭州暖湖/惠州荔红/儋州沧溟/常州归静）；
   - **Scene 3 (测试结果揭晓)**：0.8~1.2 秒克制粒子聚拢效果，随后平滑过渡至对应站点专属情绪光晕，完全不阻断 DOM 结果阅读。
4. **性能预算与四档动态降级**：
   - 初始使用 Medium/Low 档启动；
   - 严格限制 DPR：`min(devicePixelRatio, 1.5)`（低档 DPR=1.0）；
   - 像素预算：总像素 ≤ 200 万；
   - 绘制调用：draw call ≤ 25/帧，三角形 ≤ 5k/帧（远低于官方上限）；
   - 帧耗时监控：持续掉帧（>33ms）自动降档；
   - `visibilitychange` 后台休眠；
   - `webglcontextlost` 捕获停帧与安全恢复；
   - `prefers-reduced-motion` 动效退化。
5. **自动化测试与官方审计闭环**：
   - 编写任务 15.1 专属测试套件 `scripts/test_effects_flow.py`，全覆盖引擎初始化、档位切换、场景挂载、销毁释放、context lost 容错与纯静态降级；
   - 运行全量回归测试套件与官方 Skill 1.6.0 Python & Node.js 双引擎双对象审计；
   - 使用 Chrome DevTools MCP 在 390×844 视口下截取 WebGL 视觉成果留证；
   - 产出成果说明并提交 Git。
