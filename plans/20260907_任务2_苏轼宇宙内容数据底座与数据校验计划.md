# 任务2 苏轼宇宙内容数据底座与数据校验计划

## 任务目标
严格执行 `tasks/任务2_苏轼宇宙内容数据底座与数据校验01.md`，基于 `docs/02`、`docs/05` V1.1、`docs/06`、`docs/07` 与 `tasks/00` 规范，建立纯本地结构化数据底座（涵盖九大人生站点、核心历史事件、代表作品、诗词名句、8类生活状态、测试题库、30条今日东坡与权威史料来源），建立纯离线 Classic Script 编译装载机制（彻底杜绝运行时 `fetch`），编写自动化数据校验脚本 `scripts/validate_content.py`，并与官方 Skill 1.6.0 双重审计集成闭环。

## 执行步骤
1. **建立权威来源与稳定 ID 体系**：
   - 创建 `data/sources.json`：收录《宋史·苏轼传》、《苏轼全集校注》、《东坡乐府笺》、孔凡礼《苏轼年谱》等权威出处；
   - 确立统一小写下划线稳定 ID 规范（如 `station_huangzhou`, `work_dingfengbo_moting`, `quote_dingfengbo_01`, `mood_anxious`, `quiz_01`, `daily_001`）。
2. **构建全套核心结构化数据文件**：
   - `data/stations.json`：9 个核心人生站点完整字段（时间、年龄、地点、关键词、简史、东坡理解、行动建议、作品引用与审核状态）；
   - `data/events.json`：核心历史事件（乌台诗案、黄州躬耕、筑苏堤、定惠院寓居等）；
   - `data/works.json`：精选 20~25 首代表作品，关联站点与背景；
   - `data/quotes.json`：30~50 条核心诗文引文，严格区分古代原文与产品解读，绑定出处；
   - `data/moods.json`：8 类当代生活状态及与人生的映射维度；
   - `data/quiz.json`：7 道生活化测试题，选项多维度加权与 tie-break 规则；
   - `data/daily-dongpo.json`：30 条今日东坡卡片数据（按日期哈希稳定轮换）；
   - 所有数据条目均标记 `review_status: "approved"`。
3. **设计纯离线数据装载机制（杜绝运行时 fetch）**：
   - 编写构建工具，将 `data/*.json` 合并编译生成静态脚本 `js/data.js`，挂载在 `window.SuShiUniverse.Data`；
   - 在 `index.html` 中外置引入 `<script src="./js/data.js"></script>`，实现 100% 离线、零网络加载、Chrome 61 兼容。
4. **编写自动化数据校验脚本**：
   - 编写 `scripts/validate_content.py`：校验 JSON 语法、ID 唯一性、外键引用完整性、必填字段、审核状态合法性、测试题可达性、文本体积告警（单文件 ≤2 MiB，总量 ≤5 MiB）及无违禁敏感词。
5. **集成构建与官方 Skill 1.6.0 双重审计**：
   - 升级 `scripts/build_and_audit.py`，在构建前自动调用数据校验，打包生成离线 ZIP 并执行官方 Python 与 Node.js 审计；
   - 启动本地测试服务验证数据装载与交互。
6. **归档交付与提交代码**：
   - 编写成果说明文档（含 `tasks/00` 规定的合规自检清单）；
   - 追加更新 `开发日记.md`；
   - 提交 Git Commit。
