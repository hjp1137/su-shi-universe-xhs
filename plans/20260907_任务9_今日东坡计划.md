## 一、任务目标与核心理解

根据 `tasks/任务9_今日东坡01.md`：
1. **轻量文化陪伴高频入口**：
   - 让产品从一次性测试工具升级为每天可以打开一次的轻量文化陪伴工具；
   - 固定内容结构：
     > **一句东坡诗词 + 一段真实背景 + 一句东坡式理解 + 一个今日小行动。**
2. **稳定日期映射算法**：
   - 同一自然日（中国本地时间）多次打开/刷新 100% 稳定获得同一条内容，杜绝随机抽取；
   - 跨日自然平滑轮转；
   - 零网络请求，纯本地确定性哈希算法；
   - 异常日期与空数据优雅降级至默认审核内容。
3. **首页动态联动**：
   - 首页“坐一会｜今日东坡小笺”卡片升级为展示今日实际诗句 + 短理解 + “坐一会儿”直达入口；
   - 首页与 Daily 详情页严格消费同一条离线数据。
4. **内容体验与安全边界**：
   - 30 条已审核内容覆盖丰富生活面向（风雨、明月、山水、好好吃饭、读书、友情、家人、休息、接受不完美、日常快乐等）；
   - 今日小行动必须低门槛、低成本（5~15分钟内完成）、无消费依赖、无心理治疗承诺；
   - 区分古人原话、历史事实与现代生活启发，杜绝成功学与廉价鸡汤。
5. **Milestone B 集中自检与官方双重审计**：
   - 串联并验证全链路：首页 → 测试 → 结果 → 人生宇宙 → 作品内容 → 今日东坡；
   - 完全离线断网、Chrome 61 兼容、无 ESM/内联 JS；
   - 官方 Python & Node.js 双重审计通过，包体控制在 110 KB 左右。

## 二、架构设计与详细规划

### 1. 独立模块封装 (`js/daily.js`)
- 封装 `SuShiUniverse.Daily`：
  - `getTodayDateString(optDate)`: 输出 `YYYY-MM-DD` 格式的本地日期字符串；
  - `stableDateHash(dateStr)`: 确定性 32 位整数哈希算法；
  - `getTodayItem(optDate)`: 根据本地日期映射获取 `daily-dongpo.json` 中的条目；
  - `getItemByDate(dateStr)`: 按任意日期字符串获取条目（供单测与日期切换测试）；
  - `buildDailyShareCardViewModel(dailyItem)`: 输出给分享卡的纯数据模型。
- 在 `index.html` 中以 Classic Script 规范引入 `<script src="js/daily.js"></script>`。

### 2. 首页今日东坡小笺预览联动 (`js/views.js` - `home`)
- 首页路径 3 卡片改为展示今日真实推荐：
  - “今日诗句”（如：“莫听穿林打叶声，何妨吟啸且徐行。”）；
  - “今日理解”（`dailyItem.dongpo_view`）；
  - “坐一会儿 →”入口；
- 与 `daily` 详情消费同一条数据。

### 3. 今日东坡详情页升级 (`js/views.js` - `daily`)
- **日期印章头部**：当前阳历日期 + 风雅节气/季节标示；
- **名句书法卡片**：展示今日名句、作品名《作品名》、所属站点直达；
- **真实生活背景**：苏轼写下这句诗时的真实历史与生活现场；
- **放到今天（东坡式理解）**：当代生活启发，标明非古人原话；
- **今天只做一件小事**：低门槛日常小践行；
- **关联人生站点直达**：点击直达对应站点详情页；
- **生成“今日东坡签”**：导航至分享卡预览页；
- **多向导航**：漫游人生宇宙、测测我的状态、返回首页。

### 4. 视觉设计系统 (`css/views.css`)
- `.daily-container`: 纵向诗意布局；
- `.daily-date-stamp`: 水墨朱砂印章风日历标头；
- `.daily-quote-card`: 书法名句与出处芯片；
- `.daily-narrative-card`: 生活背景与现代理解卡片；
- `.daily-action-card`: 日常小行动温润卡片；
- `.home-daily-preview`: 首页诗句与理解轻预览样式。

### 5. 自动化测试与工程验证
- 编写 `scripts/test_daily_flow.py`，测试同日稳定性、30天轮换、次日切换、外键完整性、小行动安全词库与异常降级；
- 运行 `python scripts/build_and_audit.py`，通过官方双重审计；
- 启动临时本地服务，利用 chrome-devtools-mcp 在 390x844 视口下截取 6 张标准成果截图；
- 测试完毕后立即关闭后台测试服务；
- 集中执行 Milestone B 全链路（首页→测试→结果→宇宙→作品→今日东坡）自检。
