## 一、核心目标与执行理解

在任务1至任务11构建的核心功能（心境测试、人生站点、漫游宇宙、诗词作品详情、今日东坡、Canvas海报、Native Bridge发布）完全可用且合规的基础上，本任务集中进行视觉与交互的动效氛围收口与移动端体验升级：
1. **东方古典水墨动效氛围**：在严格的 Chrome 61 / 移动端 WebView 高性能约束下，增加克制、优雅的纯 CSS 水墨氛围微交互（月光呼吸 `moonBreathe`、水墨流光微动 `riverDrift`、薄雾浮沉 `mistFloat`、星点低频闪烁 `starTwinkle`、视图入场淡入浮起 `viewFadeIn`、测试选项卡轻回弹、结果页层级展开 `staggerFadeIn`、生命线站点呼吸脉冲 `stationPulse`）。严禁 WebGL、严禁外部动效库，仅操作 `transform` 与 `opacity` 保障 60fps。
2. **Chrome 61 CSS 集中纠偏**：
   - 修复 `.share-card-actions` 等区域裸漏 `gap:` 属性，补齐 sibling margin（`> * + *`）Chrome 61 基线兼容；
   - 修复 `.share-card-img-wrap` 依赖 `aspect-ratio` 在老核上高度塌陷风险，补齐 min-height 与回退容器；
   - 确认无未处理的 `clamp()`、`:has()` 或裸漏现代逻辑属性。
3. **移动端触控体验与双安全区适配**：
   - 全局交互强化 `:active` 与 Pointer Events 点击反馈（缩放微动效、墨色高亮、防抖）；
   - 检查并巩固双安全区容器：顶部与底部使用 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))`；
   - 保证长文本安全换行与信息流缩放识别度，杜绝任何页面出现横向滚动与溢出；
   - 支持系统 `@media (prefers-reduced-motion: reduce)` 优雅降级。
4. **自验证与官方双重审计闭环**：
   - 编写 `scripts/test_motion_flow.py`，覆盖动效 CSS 规范、Chrome 61 兼容规则、媒体查询降级与双安全区校验；
   - 运行全量测试并执行 `python scripts/build_and_audit.py`，确保 Python 与 Node.js 双重审计全绿，离线 ZIP 包体远低于 2MB；
   - 启动本地服务，使用 Chrome DevTools 移动端视口（390×844）截取规范成果截图，保存至 `Walkthroughes/screenshots/20260907_任务12_动效氛围与移动端体验升级/`，测试结束后及时终止后台服务；
   - 输出成果说明与更新开发日记，提交 Git 记录。

## 二、详细修改规划

### 1. CSS 体系增强与动效设计（`css/tokens.css`, `css/base.css`, `css/components.css`, `css/views.css`）
- `css/tokens.css`：
  - 增加水墨动效关键缓动与周期变量：`--motion-breath`, `--motion-drift`；
- `css/base.css`：
  - 在 App Shell 增加水墨意境背景光晕微动；
  - 增加 `@media (prefers-reduced-motion: reduce)` 全局降级规则，确保低功耗或开启减弱动画的设备不消耗多余资源；
- `css/components.css`：
  - 增强按钮、卡片、导航返回键的 Pointer/Touch `:active` 反馈；
  - 增强 Toast 与 StateBox 的淡入与水墨光圈微动；
- `css/views.css`：
  - 修复 `views.css` 第 1266 行的 `gap: var(--space-3);`，增加 `.share-card-actions > * + * { margin-top: var(--space-3); }`；
  - 修复 `views.css` 第 1220 行的 `aspect-ratio: 3 / 4;`，增加基线 `min-height: 380px;` 回退；
  - 给所有核心视图容器添加入场动效类 `.view-wrapper`：`animation: viewFadeIn 300ms cubic-bezier(0.2, 0, 0.2, 1) forwards;`；
  - 首页：增加月影与江水背景氛围层微动、Hero 徽标微妙浮光；
  - 问答页：选项卡片选中态轻上浮与微光、下一题切换平滑淡入；
  - 结果页：首屏卡片、深度解读卡、今日小行动三级卡片阶梯级展开（stagger delay 0ms, 80ms, 160ms）；
  - 漫游页：生命线当前结果节点与核心转折点增加低频脉冲呼吸圈（`stationPulse`）；
  - 分享页：海报卡预览增加水墨画卷感阴影与轻盈浮现。

### 2. JS 交互细节与状态保护（`js/router.js`, `js/views.js`, `js/ui.js`）
- 视图切换时，确保滚动条自动平滑重置到顶部（`appMain.scrollTop = 0;`）；
- 视图容器自动挂载动效进入类，离开时清理残留；
- 避免定时器或动画在隐藏视图中泄漏。

### 3. 自动化测试脚本编写（`scripts/test_motion_flow.py`）
- 测试 CSS 关键帧与动画类存在性（`viewFadeIn`, `moonBreathe`, `stationPulse` 等）；
- 测试 `@media (prefers-reduced-motion: reduce)` 是否生效；
- 扫描全量 CSS 文件，检测是否裸漏 Chrome 61 危险属性（`gap:` 必须有 sibling margin 伴随，`aspect-ratio` 必须有 min-height，无裸漏 `clamp()`、无 `:has()`）；
- 测试双安全区 fallback 规范性；
- 测试所有视图结构渲染不发生横向溢出标记。
