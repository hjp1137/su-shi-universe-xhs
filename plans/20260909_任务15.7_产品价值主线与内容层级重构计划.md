## 一、产品北极星与核心对象架构

### 1.1 产品北极星
**“借苏轼的人生，找到此刻的自己。”**
- 用户明确获得：
  1. 我现在更像苏轼人生中的哪一站？
  2. 苏轼在类似处境中，是怎样走过来的？
  3. 今天我能带走一句什么话、做一件什么小事？

### 1.2 核心产品对象：我的东坡答案 (DongpoAnswer)
在 `js/quiz.js` 中抽象导出 `Quiz.buildDongpoAnswer(stationId, moodId)`，返回统一且稳定、可复用的领域对象：
```javascript
{
  stationId: string,
  stationName: string,
  stationTheme: string,
  stationShortName: string,
  quote: string,
  quoteSource: string,
  insight: string,
  microAction: string,
  topTraits: string[]
}
```
Result 页面和 `station_result` 分享卡以及站点详情的上下文全部严密绑定该对象，彻底消除文案拼接与语义矛盾。

## 二、首次体验唯一主线与页面层级重构

### 2.1 首次主线（2~4 分钟极简闭环）
`首页 → 东坡人生实验 → 我的东坡答案 → 生成/保存人生卡 → 可选深入探索`

### 2.2 首页 (Home) 重构
1. 第一屏唯一核心问题：**“你的人生，正走到苏轼的哪一站？”**
2. 副说明：**“七次宇宙选择，找到此刻最接近你的东坡人生。”**
3. 唯一主 CTA：**“开始我的东坡人生实验”**；
4. 主 CTA 下方三项轻量用户收益提示（390×844 不滚屏清晰可见）：
   - 测一测：找到我的人生站点
   - 读一句：得到苏轼给此刻的回答
   - 带走它：生成我的东坡人生卡
5. 次级入口治理：原本的“逛一逛 九大人生星河”与“坐一会 今日东坡诗签”降为首屏下方的轻量次级入口，不再与主 CTA 争抢同级权重。

### 2.3 东坡人生实验 (Quiz)
- 保留现有的 7 幕星体碰撞与心境吸附玩法；
- 优化引导提示，让用户始终感知“正在完成七次选择，以获得我的东坡答案”；
- 完成第 7 幕后直达“我的东坡答案”结果页。

### 2.4 Result 页面重构为“我的东坡答案”
- 唯一 L1：“我的东坡答案 / 站点名称｜人生主题”；
- 紧凑 L2：
  - 一句核心东坡诗句
  - 给此刻的你（东坡哲思）
  - 今天的一件小事（日常微行动）
- 两个明确动作：
  - 主动作：**生成我的东坡人生卡**（Primary Button）
  - 次动作：**进入XX小宇宙**（Secondary Button）
- 剥离冗余历史长篇百科与长标签，不与站点详情同质化。

### 2.5 人生星河 (Universe) 叙事弧线化
- 九大站点形成清晰人生弧线标签：
  - 眉山｜出发
  - 京师｜被看见
  - 密州｜豪情
  - 乌台｜坠落
  - 黄州｜重生
  - 杭州｜把日子过好
  - 惠州｜随遇而安
  - 儋州｜极境从容
  - 常州｜归途
- 节点点击 Quick Sheet 只做极轻量预览，引导“进入本站小宇宙”。

### 2.6 今日东坡 (Daily) 纯粹化
- 核心聚焦“每天给我一句东坡”：一张大图 + 一句诗 + 一句理解 + 一件小事 + “生成今日诗签”主 CTA；
- 历史背景折叠为次级详情 `<details class="daily-history-details">`（“✦ 读这句诗背后的东坡”），消除双重背景卡重复；
- 严禁正文内嵌完整海报，保持轻量。

### 2.7 站点详情 (Station) 明确为深入探索
- 顶部新增“你为什么来到这里”的上下文提示：
  - 若来自实验结果：“你的东坡答案落在这一站。继续看看苏轼当年是怎样走过来的。”
  - 若来自人生星河漫游：“你正在探索苏轼人生的「XX时刻」。”
